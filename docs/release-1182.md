# 1182 · 화면 통폐합 묶음 (노트 · AI 분석 · 임장 가이드 · 정비사업 · 지도)

## 바뀐 것

| 화면 | 내용 |
|---|---|
| 임장노트 목록 | 피드가 먼저(PC · 폰). 목록은 한 줄(점수 · 제목 · 지역·시각). 썸네일 · 막대 · 사진 칸 없음 |
| AI 분석 지도 서랍 | 지도만(목록은 지도가 안 뜰 때만). 단지명 검색 크고 진하게. "단지 없이 … 먼저 보기"는 맨 아래 |
| AI 분석 결과 4종 | "다음 행동" → "추천 기능". 근거 · 출처 / 자세히 보기 한 줄씩(개수는 제목 옆 · 오른쪽은 꺾쇠). 면책 문단은 화면 폭(문장 그대로) |
| 임장 가이드 | 체크포인트 10개 두 열. 쓰기 버튼은 제목 줄 |
| 정비사업 지도 | 메뉴 순서 동네이야기 → 정비사업 지도 → 전문가 → 입주 물량 → 청약 센터 → 공매 물건 |
| 정비사업 요약 | 숫자 칸 + 단계 막대 7줄 → 한 줄. 단계별 구역 수는 진행단계 칩 옆 숫자 |
| 정비사업 7단계 | 칩 줄 + 상세 7줄 → 칩 줄 하나. 누르면 창(소요 · 설명 · 유의점 · 확인 사항 · 면책) |
| 정비사업 데이터 출처 | 표 + 면책 띠 → 한 줄. 누르면 창 |
| 정비사업 목록 탭 | 삭제. 내용 탭의 분포 줄(사업종류 · 진행단계 · 지역)을 누르면 그 구역 목록이 창으로 |
| 서울시 결정 조서 | 최근 5건 + "더 보기" |
| 지도 필터 | 절 제목 크게 · 진하게, 작은 제목은 칩 윗줄, 칩에 테두리(고른 칩은 파란 테두리) |
| 지도 정비사업 레이어 | 기본 켬. 끈 상태는 주소(noredev) · 저장값으로 기억 |
