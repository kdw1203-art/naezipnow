# 1185 · 같은 말 두 번 정리 (정비사업 7단계 · 공매)

## 진행 전 재검토

어제 표의 2~7번을 화면에서 다시 확인했다. 글자 수로 센 "반복"의 상당수는 실제로 보이는 중복이 아니었다.

| 화면 | 다시 본 결과 | 처리 |
|---|---|---|
| 정비사업 7단계 | 면책 문장이 단계 창마다 7번(1182에서 생긴 것) | 한 번으로 |
| 공매 | 물건 이름 끝의 용도 + 용도 칸(같은 말 두 번) · 출처 접기 두 개 | 이름에서 떼고 접기 하나로 |
| 청약 | 같은 단지 이름 반복은 화면에 안 보임(읽기 프로그램용) · 폰/PC 판이 따로 있어 두 번 세어짐 | 손대지 않음 |
| 고객센터 | 지난 정리(1015 · 1028)에서 이미 줄였고 남은 것은 메뉴와 본문 제목 | 손대지 않음 |
| 동별 · 실거래 구간 | "N곳 더 ›"는 시군구마다 다른 링크 | 손대지 않음 |
| AI 분석 허브 | 지역 표 67줄은 표 내용 | 손대지 않음 |
| 요금 안내 | 결제 고지와 묶여 있어 구조 변경은 따로 판단 필요 | 손대지 않음 |

## 바뀐 것

- 정비사업 7단계: 면책 문장 한 번(칩 줄 아래).
- 공매: "… [근린생활시설]" · "… 308-1호 근린생활시설"처럼 용도 칸과 같은 말은 이름에서 뗀다. "기준 · 출처"와 "출처 · 면책" 접기를 하나로.

## 하지 않은 것

- 첫 방문 속도(/dong · /rent · /redevelopment)와 부산 지역 화면 시간 초과: 원인을 아직 찾지 못했다.
