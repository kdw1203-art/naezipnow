## 바뀐 것

### 995-1 · 단지 SEO (D1)
- 제목·설명이 검색 의도("단지명 시세/실거래/평형")에 맞게: `{단지} 실거래가 {가격} ({YY.M월}) · {읍면동} 시세·평형별
  실거래 | 내집나우`, 설명에 최근 12개월 건수 · 평형별 최근가(면적대 2개) · 세대수 · 준공. 값이 없는 조각은 통째로 뺀다.
  읍면동은 대표행 address 에서 파싱(`lib/complex/dong.ts`, 순수·단위테스트 9).
- 첫 화면(히어로 아래) **평형별 최근 실거래 칩** 최대 3개(면적대 · 최근가 · 기준월) → 아래 면적대 표로 앵커.
  이미 띄운 로더를 같이 쓰므로 질의 0 추가.
- 내부 링크: "다른 단지"가 **읍면동 우선**(같은 동 3곳 미만이면 구로 물러선다 — 라벨도 그때만 "구"), 브레드크럼에
  `{시} {구}` → `/region/{id}` 링크, JSON-LD BreadcrumbList 3단(홈 → 지역 → 단지), `addressLocality` = 읍면동,
  `twitter:card summary_large_image` 추가(없어서 X 는 작은 카드였다).
- 곁가지 수정: `regionIdForName("부산")` 부분 일치로 부산 단지 전부가 중구를 가리키던 것(시/도 대조로 교정), 자기 단지가
  "다른 단지"에 섞이던 것(canonical_id 로도 제외).

### 995-2 · 공유 카드 유입 (D2)
- **짧은 링크** `naezipnow.com/n/{code}`(공개 노트 uuid 앞 8자) — 카드 모든 장 하단·마무리 장에 인쇄. `/n/{code}` 는
  공개 노트면 `/notes/{id}?utm_source=card&utm_medium=image&utm_campaign=note-card` 로, 아니면 `/notes?utm_source=card`
  로 302(인쇄된 링크는 되돌릴 수 없으니 404 없음). 조회는 uuid PK 범위 스캔(추가 인덱스·마이그레이션 없음).
- 카드 스튜디오 공유 줄(공개 노트): **이미지로 공유**(iOS·안드로이드는 PNG 파일을 OS 공유 시트로 → 카카오톡 1탭,
  데스크톱은 저장) · **링크 복사**(짧은 링크) · **카카오톡**(`NEXT_PUBLIC_KAKAO_JS_KEY` 가 있을 때만 — 지금은 없음).
- 계측: `card_share{channel}` · `card_export` · `share_link_copy`(정의만 있고 발화가 없던 것) → `/admin/traffic` 라벨.
  `/admin/traffic` 에 **공유 유입(30일)** 표: 출처(card/share/kakao) · 랜딩 · 세션 · 단지 열람 · 가입/로그인 진입.
- 곁가지 수정: 카드 "항목별 점수"가 1~5 원값을 0~100 틀에 넣어 "4 / 100" 으로 찍히던 것 → ×20(상세·피드와 같은 규칙).

### 995-3 · 노트 회차 · 자동 관심 (S4 · S5)
- **`/notes/new?revisit={noteId}`**: 소유자면 이전 노트의 위치·태그·유형/목적·체크리스트를 불러와 새 노트로 시작
  (사진·메모·만족도·현장 체크는 새로). 배너 "재방문 · {날짜} 기록을 불러왔어요 · 이번이 N회차" + 이전 노트 보기 · 비우기.
  2단계 현장 체크 옆 **지난 체크** 띠(✓ – ✗ 최대 6). 저장 메타 `revisitOf`·`round`(단지가 바뀌면 끊는다).
  노트 상세의 재방문 버튼이 이 경로로.
- **자동 관심**: 단지 id 가 있는 새 노트를 저장하면 관심 단지에 넣는다(수동 등록과 같은 플랜 한도 판정, 이미 있으면
  무동작). 처음 넣을 때만 수신함 안내 + 해제 경로. 응답을 막지 않고 `after()` 로 완료를 보장.
  → `watchlist-new-tx` 크론이 임장 다녀온 단지의 새 실거래를 알린다.

### 995-4 · 개인 주간 요약 (D3)
- `weekly-digest` 가 **사람마다 다른 요약**을 만든다(`lib/digest/personal.ts`): 관심 지역 ≤5(평균 매매·전월비·거래 건수·
  기준월) · 관심 단지 새 실거래(7일, 최근가·신고일) · 임장 다녀온 단지 중 새 실거래 · 관심 지역 청약 접수 시작(7일,
  994 저장소). 비면 섹션을 뺀다 — 전부 비면 기존 공통 요약으로 폴백. 사용자당 질의 3 · 4초 예산 · 동시 4 · 전체 95초.
- 수신 기본값 정합: DB 기본 `push_weekly_digest=false` 인데 코드·설정 화면은 "켜짐" — 설정 행이 없는 사람이 조용히
  빠지고 있었다 → `coalesce(push_weekly_digest, true)`. **이메일은 `email_marketing=true` 명시 동의자만**(제목 `(광고)`),
  인앱·푸시는 다이제스트 설정만 본다. `?dry=1` 은 미리보기 3건.
