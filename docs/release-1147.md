# 1147 — 관리자 2단계 인증(인증 앱) · 가입 걸음 계측

## 관리자 2단계 인증
- 인증 앱(Google Authenticator · Microsoft Authenticator 등)의 6자리 번호(TOTP · 30초)를 로그인 뒤 한 번 더 확인한다. 확인하면 그 브라우저에서 12시간 유지.
- 등록은 선택: 등록 전에는 예전처럼 들어가고, 관리자 화면 위에 "2단계 인증 미등록" 띠가 뜬다. 등록을 마친 계정은 번호 확인 없이는 관리자 화면(/admin 전체)에 못 들어온다.
- 등록: /admin-2fa → "등록 시작" → QR 을 인증 앱으로 찍거나 열쇠 직접 입력 → 6자리 번호 확인.
- 비밀값은 AUTH_SECRET 에서 뽑은 열쇠로 암호화해 admin_totp 표에 둔다(서버만 접근). 등록을 마친 뒤에는 다시 내보내지 않는다. 번호 시도는 10분에 8번.
- 인증 앱을 잃어버리면: Supabase SQL 편집기에서 `delete from public.admin_totp where email = '<관리자 이메일>';` 실행 → 다시 등록.
- 한계: 화면(/admin/*)만 막는다. 관리자 API(/api/admin/*)는 예전처럼 로그인 + 관리자 권한만 본다 — 다음 작업에서 같은 확인을 붙인다.
- 실제 등록 · 확인 흐름은 운영 DB 로 돌려 보지 못했다(계산 규칙은 RFC 6238 시험값으로 검증). 적용 뒤 소유자 계정으로 한 번 등록해 확인 필요.

## 가입 걸음 계측
- 가입 폼 두 걸음 사이에 표식(signup_step_2_basic)을 남긴다. 관리자 › 트래픽의 이벤트 표에서 "가입 1단계 → 2단계(기본 정보 도착) → 제출 누름 → 완료" 수를 견줘 어디서 그만두는지 본다.

DB: admin_totp 표(2026-11-11 운영 반영 완료).
