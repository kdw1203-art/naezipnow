## 광고

- 좌우 띠(`SideAdRails` · 루트 레이아웃): 본문 열 바깥 왼쪽 · 오른쪽 여백에 160px 세로 띠 하나씩.
  본문 1240px 화면은 1640px 부터, 넓은 본문(1400px) 화면은 1800px 부터 보인다. 고정 아님(스크롤하면 같이 올라간다).
- 띠가 보이는 동안 본문 흐름 가운데 광고(`AdZone data-spot="center"` — 홈 피드 · 목록 사이 · 본문 안)는 숨는다.
  옆 열 · 글 끝 · 페이지 끝(`data-spot="side"`)은 그대로 — 가운데에는 작은 남는 자리만.
- 폰 · 1640px 미만 화면은 여백이 없어 예전 그대로.
- 제외 경로(결제 · 요금제 · 내 정보 · 로그인 · 지도 …) · 관리자 · 광고 없는 플랜에는 띠가 나가지 않는다(`SideRailGate`).

## 처음 온 사람의 길

- `StartSteps`(비회원에게만 · 로그인 힌트가 있으면 걷는다): 1 회원가입 → 2 임장노트 → 3 지도 → 4 AI 분석 + "중개사 · 전문가 등록".
- 놓인 곳: 홈(검색 띠 아래) · 공개 임장노트 상세 끝 · 뉴스 상세 끝. 가입 링크는 읽던 화면으로 돌아오는 `callbackUrl` 을 싣는다(내부 경로만).
