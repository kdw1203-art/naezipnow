# 1169 — 전문가 등록 홍보 안내 아래로 · 모임 채팅 바로가기 · MY 내 모임

소유자 2026-11-12 "(등록 뒤 홍보 칸) 하단으로 위치" · "그 외 개선사항 찾아서 진행".

## 바뀐 것
- 전문가 등록: "등록 뒤 홍보" 안내를 신청 칸 아래로 옮겼다(단계 → 신청 칸 → 홍보 안내). 4단계 문구 "홍보 100일 무료" → "홍보 1년 무료".
- 모임 채팅: 위에 일정(다가오는 수) · 게시판 · 투표 바로가기. 모임 테이블이 없는 DB 에서는 안 보인다.
- MY: "내 모임 N곳" 한 줄 — 가장 가까운 일정(날짜 · 시간 · 이름). 모임이 없으면 줄 없음.
- 모임 상세: 이미 참여한 멤버에게는 "모임 채팅방 입장 · 참여 중인 모임"으로 표기(1168 에 포함).

## 확인
- 단위 시험 2,670 통과 · 전체 빌드 통과 · 변경 전후 이미지 3장(예시 자료).
- 채팅 이미지는 로컬에서 쓰기 요청을 막고 찍어 "참여 후 이용" 안내가 보인다(운영에서는 참여 멤버에게 대화가 보인다).
