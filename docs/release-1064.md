# 1064 — 레일포털(철도산업정보센터) 도시철도 연동 (2026-10-13)

소유자가 승인 메일을 전달(2026-10-12). 승인 범위 세 가지를 모두 붙였다 — 소유자 선택 "세 가지 모두".

| 서비스 | 오퍼레이션 | 받는 것 |
| --- | --- | --- |
| trainUseInfo | subwayRouteInfo | 도시철도 전체 노선·역(역 코드·이름·순서, 좌표가 오면 좌표도) |
| convenientInfo | stationTransferInfo | 역사별 환승 노선 |
| trainUseInfo | subwayTimetable | 열차별 운행시각표 → 역별 첫차·막차·편수로 접어서 저장 |

**제공 범위는 도시·광역철도뿐이다**(일반역·KTX 제외 — 공급자 안내). 화면 문구도 그렇게 적는다.

## 키 취급

- 값은 **Vercel 환경변수 `KRIC_SERVICE_KEY`** 에서만 읽는다. 코드·문서·로그·오류 메시지·관리 화면 어디에도 값을 적지 않는다
  (`redactUrl` 이 주소의 `serviceKey=` 를 `***` 로 가린다 · 시험 W1·W5 가 이를 잠근다).
- 메일로 받은 키가 채팅을 거쳤으므로 소유자에게 **재발급**을 권했다. 키가 없으면 크론은 `skipped` 로 조용히 끝난다.

## 하루 1회 배치 (공급자 요청)

"1일 1회 GET 또는 배치" 요청을 코드로 지킨다. `.github/workflows/etl.yml` 에 **하루 한 줄**만 넣었고(시험이 호출 줄 수를 1로 고정),
한 번 돌 때:

1. 노선·역 — 한 번에 통째로(작은 표).
2. 환승 — 한 번에 통째로.
3. 시각표 — 역 목록을 **돌아가며 60곳씩**(`rollingSlice` · 커서는 상태에 저장). 역 1,000곳이면 보름쯤에 한 바퀴.
   요일은 평일(8)부터 — 토·휴일은 다음 바퀴에서 채운다. 역 하나가 막혀도 배치는 멈추지 않는다.

## 저장 자리 — 표를 새로 만들지 않는다

이 저장소는 마이그레이션을 쓰지 않는 규약이라(1057 이후), 1061 검색 기록과 같은 `public.kv_store_99a854cb`(key·value jsonb ·
service_role 전용)에 접두사로 넣는다: `rail:lines` · `rail:transfers` · `rail:timetable:<역코드>` · `rail:state`.

## 응답 규격을 모른다는 사실을 설계에 넣었다

레일포털 규격 문서가 로그인·첨부파일 뒤에 있어 **응답 열 이름을 확정할 수 없다**. 그래서

- 파서는 어느 깊이에 있든 "객체들의 배열" 가운데 가장 큰 것을 줄로 삼고, 결과 코드·메시지는 흔한 이름들에서 찾는다.
- 열 이름은 별칭 표(`ALIAS`)로 읽는다 — 역 코드가 없는 줄은 버리고, 한국 영역 밖 좌표(0,0·자리바꿈)는 쓰지 않는다.
- **첫 배치 뒤 관리 › 데이터 관리 맨 위 "도시철도 — 레일포털" 칸에 실제 열 이름이 그대로 찍힌다.** 그걸 보고 별칭 표를 한 번 맞춘다.

## 아직 하지 않은 것

- 단지 상세에 "가까운 역"을 붙이는 일은 **역 좌표가 실제로 오는지 확인한 뒤**다. 노선정보에 좌표가 없으면 공공데이터포털
  도시철도역사 위치 표준데이터(`POI_STATIONS_API_PATH`, 승인 대기) 가 여전히 필요하다. 관리 화면의 "좌표 있는 역" 숫자가 그 답이다.
- 이 키는 `POI_STATIONS_API_PATH` 를 대신하지 않는다(다른 기관·다른 데이터).

## 소유자가 할 일

1. Vercel › Environment Variables(Production)에 `KRIC_SERVICE_KEY` 추가 → 재배포. 값은 채팅에 붙이지 않는다.
2. 다음 ETL(매일) 뒤 관리 › 데이터 관리 › 도시철도 칸에서 역 수·좌표 있는 역 수·열 이름을 캡처해 보내 주면, 별칭 표를 맞추고
   단지 상세 연결을 잇는다.
3. 노출된 키는 레일포털에 재발급 요청.

## 검증

- 빌드 EXIT 0 · 단위 `review-1064` 5건 포함 전체 통과 · 게이트 통과. 샌드박스에서 `openapi.kric.go.kr` 로 나가는 길이 막혀 있어
  **실제 호출은 하지 않았다**(키도 쓰지 않았다) — 첫 호출은 운영 ETL 이 한다.
