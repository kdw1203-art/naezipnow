# release-1193 · 지도 위 창 정리

소유자 요청(2026-11-16): "지도에 띄워 있는 창이 너무 많아 보여 정리해줘".

| 창 | 전 | 후 |
|---|---|---|
| 실거래 평단가 범례(좌하단) | 늘 펼침 | 범례 한 장으로 합쳐 접힘 — 색 막대 한 줄 + "범례 ▴" |
| 가격 표기 안내(좌하단) | 별도 카드 | 범례 안 |
| 정비사업 종류(우하단) | 별도 카드 | 범례 안 |
| 임장한 단지 · 미방문(우하단) | 별도 카드 | 범례 안 |
| 등록 매물 없음 | 제목 · 설명 · 단추 둘 카드 | 한 줄(조건을 좁혔을 때만 "필터 초기화") — "매물 등록하기"는 우측 "매물 등록" 단추와 같은 곳이라 뺌 |
| 처음 안내(비회원 첫 방문) | 석 줄 카드 | 한 줄 알약 |

폰 범례(접이식)는 그대로. 단위 테스트 2,690 통과 · 빌드 exit 0.
