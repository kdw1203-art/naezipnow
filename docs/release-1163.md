# 1163 — 내 임장 이력: 다녀온 단지 변동

소유자 2026-11-12 "임장 이력을 통한 개인화 정보 · 추후 변경사항 · 변동 내용 · 유사 단지 또는 해당 단지 관심도".

## 바뀐 것
- `/my/history` 에 "다녀온 단지 변동" — 임장노트를 쓴 단지(최근 방문 5곳)마다:
  - 방문 뒤 새 실거래 건수 · 방문 전 마지막 거래와의 차이(같은 평형 ±3㎡끼리만 · 해제 거래 제외 · 방문한 달의 일 모르는 거래는 세지 않음)
  - 방문 뒤 거래가 없으면 "방문 뒤 새 실거래 없음 · 최근 ○억(날짜)"
  - 관심도(조회수 · 관심 담은 사람 수 — 0 은 적지 않는다)
  - 같은 구 거래 많은 단지 3곳
  - 마지막 노트 · 다음 회차 쓰기(단지가 채워진 채로)
- 단지 하나를 못 읽으면 그 카드만 "불러오기 실패"로 그린다. 단지 id 가 없는 노트(주소만 적은 것)는 이 칸에 나오지 않는다.
- 1158~1162 포함.

## 확인
- 단위 시험 2,662 통과 · 전체 빌드 통과 · 예시 자료로 화면 캡처(변경 전후 이미지 첨부).
- "같은 구 거래 많은 단지" 줄은 예시 자료에 없어 이미지에 나오지 않는다 — 운영에서 확인.
