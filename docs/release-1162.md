# 1162 — 내 임장 이력 · "여기에 ~돼요" 문구 걷기

## 바뀐 것
- 새 화면 `/my/history`(내 임장 이력): 임장노트(방문일)와 AI 분석 기록(실행일)을 날짜 줄 하나로. 좌표가 있는 노트는 위 지도에 점으로(누르면 그 노트).
  한쪽을 못 읽으면 읽은 쪽만 보이고 실패한 쪽을 한 줄로 말한다. 마이의 "내 임장노트" 위에 들어가는 줄을 뒀다.
- "~하면 여기에 모여요/표시돼요/쌓여요" 문구 15곳을 사실 한 줄로 줄이거나 지웠다(마이 · 관심 · 상담 · 결정 · 단지 내 기록 · 홈 빈 상태 · 위젯 · AI 결과).
- 홈 화면 구성은 그대로(소유자 2026-11-12 "홈은 그대로 두는 게 좋을 것 같아") — 홈은 빈 상태 문구 두 줄만 바뀐다.
- 1158~1161 포함.

## 하지 않은 것
- 마이 개편: 살펴보니 마이는 이미 활동 요약 5칸 · 다음 할 일 · 내 노트 · 관심 · 구독 · 포인트를 모은 허브다. 순서를 바꾸는 일은 운영 화면을 보고 정한다.
- 다가오는 임장 일정: 일정 자료를 담는 기능을 확인하지 못해 만들지 않았다.

## 확인
- 단위 시험 2,661 통과 · 전체 빌드 통과. 로컬은 DB 키가 없어 이력 화면이 "불러오기 실패"로 그려진다 — 실제 목록은 운영에서 확인.
