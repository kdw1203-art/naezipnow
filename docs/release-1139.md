# 1139 — 지역 지표 채우기: 거래량 · 관심도 · 기사 수

소유자 2026-11-11 "데이터를 쌓거나 네이버, 구글을 통해 3개월 또는 6개월치 관심도, 기사, 거래량, 추이 등을 분석해서 제시".

## 왜 비어 있었나(새 DB 실측)
- 실거래 239,934건(2025-10 ~ 2026-10)은 들어와 있는데 **지역 월 집계(market_region_monthly)가 0행** — 일일 집계에 이 단계가 없고 주 1회(일요일) 잡만 있었다 → "거래량 자료 없음".
- 가격지수(market_region_series · market_region_price) 0행 — 한국부동산원 적재 크론(매일 00:50 UTC)이 새 DB 에서 아직 한 번도 돌지 않았다 → "1년 추이 · 단기 추세 자료 없음". 첫 실행 뒤 확인.
- 기사 91건(수집 하루치) → "뉴스 · 관심도 표본 적음".

## 고친 것
- sql 212: 지역 월 집계를 지금 25개월 전체로 한 번 만들고, 매일 23:20 UTC 에 최근 4개월을 다시 만든다(market-region-monthly-daily).
- 관심도: 네이버 데이터랩 검색어 트렌드 6개월(월 단위)을 지역 107곳에 대해 매일 받아, 최근 3개월 평균과 직전 3개월 평균을 견준다. 상대 지수라 지역끼리는 견주지 않는다.
- 기사 수: 네이버 뉴스 검색으로 "어제 하루" 기사 수를 지역마다 날마다 적는다. 뉴스 검색은 기간 지정이 없어 과거를 거슬러 채울 수 없다 — 14일 쌓이면 7일 대 7일, 60일 쌓이면 30일 대 30일로 말한다.
- 구글 트렌드: 공식 API 가 없어 쓰지 않는다(긁어 오지 않는다).
- 저장: public_data_cache 두 키(naver:search-trend · naver:news-daily) — 새 표 없음. 크론 /api/cron/region-buzz-ingest(매일 16:05 UTC = 01:05 KST).
