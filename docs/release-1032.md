# 1032 — 임장노트 1단계: 지도에서 고르기 · 임장한 타입 · 세부 기록 (2026-10-04)

기준: 1031(tree fe7678fd) 위에 얹는다(1029·1029b·1030 위에서도 적용 — 누적). DB 변경 없음(노트 metadata jsonb 에 키 3개 추가: `unit` · `fieldDetail` · `photoRoles`).

소유자 지시: "1단계에서 지도가 나와서 그 지도의 단지를 선택하면 자동으로 단지의 상세내용이나 내가 임장한 타입을 선택할 수 있게, 그 단지의 평면도나 내용도 알 수 있게, 이외 더 세분화·고도화된 노트".

## 1단계 — 지도에서 고르기 (app/notes/new/NoteMapPick.tsx)
- 위치 카드 바로 아래 **인라인 지도**(폰 224px · 데스크톱 288px). 재료는 /map 과 같다: `/api/map/clusters`(뷰포트·줌 → 묶음 또는 개별 단지 300곳) · 처음 축척은 `PICK_DEFAULT_LEVEL`(열자마자 단지 핀) · 내 위치 단추(SDK 지오로케이션) · 말풍선 겹침 정리.
- 마커를 누르면 검색으로 고른 것과 **같은 모양**(`NoteLocation`)을 폼에 준다 → 단지 자료 카드·임장한 타입·방문 인증이 그대로 이어진다. 묶음을 누르면 그 자리로 확대. 고른 단지는 브랜드 핀으로 표시. 검색·이어받기로 좌표가 바뀌면 지도도 그 자리로.
- 실패를 "없음"으로 그리지 않는다: 지도 SDK 실패 → "지도 불러오기 실패 · 위 검색으로 선택", 목록 실패 → "단지 목록 불러오기 실패 · 지도를 조금 움직이면 다시".
- 접기/펼치기는 이 기기만의 편의(localStorage `nz_note_map_open`).

## 1단계 — 임장한 타입 (app/notes/new/NoteUnitPick.tsx · 단지 id 있을 때만)
- 단지 자료 줄: 동수 · 최고층 · 주차(대/세대) · 난방 · 승강기 · 건설사 · 관리방식 — `/api/complex/[id]/detail` 의 complex 에 **있는 값만**(준공·세대는 위 "이 단지 한눈에" 제목이 이미 말한다).
- 타입: 그 단지 **실거래(최근 24개월, `/api/complex/[id]/trades`)에 신고된 전용면적**을 정수부로 묶은 칩 — "84㎡ · 최근 29억 · 2026.08 · 12건 · 3~24층". 실거래가 없으면 칩 대신 면적 직접 입력. 어느 쪽이든 지어낸 타입은 없다(lib/notes/unit-detail `unitTypesFromTrades`).
- 동 · 층 · 향(남·남동·남서·동·서·북·북동·북서) — 같은 단지 안에서 집을 가르는 세 값.
- 평면도: 국토부 실거래·K-apt 어디에도 평면도 자료는 없다 → "평면도 · 공공 자료 없음"이라고 말하고, 현장 안내판·분양 카탈로그를 찍은 사진을 **"평면도 사진 담기"**(같은 사진 input · 올라온 장에 역할 부여) 또는 사진 줄의 "평면도로 표시" 토글로 노트가 보관한다(`metadata.photoRoles`). 상세에는 "평면도 사진 N장"으로 적힌다.
- 저장: `metadata.unit = { areaM2, areaLabel, dong, floor, direction }`(비면 키 없음). 수정 화면에서 되읽는다. 초안(localStorage)에도 든다.

## 2단계 — 세부 기록 (app/notes/new/NoteFieldDetail.tsx)
- 체크리스트(인상)·메모(글) 옆의 **측정값·선택지** 칸: 도로 소음(없음·약간·큼) · 방문 시각 주차(여유·빠듯·만차·이중주차) · 채광(밝음·보통·어두움) · 외벽·복도 상태(양호·보통·노후) · 냄새·습기(없음·약간·심함) · 지하철 도보(분) · 초등학교 도보(분) · 승강기 대기(초) · 들은 호가(만원) · 들은 말(중개사·관리실, ≤200자).
- 전부 선택 — 비면 키를 보내지 않는다(0 이나 "보통"으로 채우지 않는다). `metadata.fieldDetail`.

## 노트 상세 (app/notes/[id]/page.tsx)
- 항목 평가 아래 "임장한 타입 · 세부 기록" 블록 — "84㎡ · 103동 · 12층 · 남향" 한 줄 + 세부 기록 표(있는 것만) + 평면도 사진 수. 셋 다 비면 블록 없음.
