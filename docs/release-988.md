# 988 — 임장노트 카드를 이미지로 (2026-09-09)

소유자 지시: **"개인 사용자가 임장노트 작성에 따른 이미지 파일을 제공할 때 2~3가지
버전으로 제공하는 디자인 양식(툴)이 있으면 좋겠다. 그리고 사용자가 작성한 내용을
바탕으로 AI가 그 디자인에 적용 + 기타 관련 정보를 추가로 넣어서 결과물을 만들어
사용자에게 제공하도록."**

---

## 1. 먼저 확인한 것 — 카드 기능은 이미 있었다

`app/notes/[id]/card` 에 카드 스튜디오가 이미 있습니다. 테마 10종, 장(프레임) 13종,
저장 API 까지. 그런데 요청과 비교하니 **세 곳이 비어 있었습니다.**

| 요청 | 있었나 |
|---|---|
| 이미지 파일로 제공 | ✗ — **내보내기가 아예 없음.** 화면으로 보고 끝 |
| 2~3가지 버전 | ✗ — 테마 10 × 장 13 = 130가지를 사용자가 직접 조합하는 **빌더** |
| 관련 정보 추가 | ✗ — 노트 자기 필드만. 실거래·전세가율 없음 |
| AI 가 내용 구성 | ✗ — 없음 |

만들어진 카드가 0건인 이유가 여기 있습니다. 고르는 데 130가지를 넘겨받고,
다 골라도 **가지고 나갈 수가 없었습니다.**

## 2. 고친 것

### ① 이미지로 내려받기

미리보기 아래에 **"이 장 이미지로 저장"** 버튼. `1080×1350 PNG` 로 떨어집니다 —
카카오톡·인스타그램에서 잘리지 않는 4:5 입니다.

서버에서 PNG 를 그리는 방법(next/og)도 있었지만 쓰지 않았습니다. 그러려면 장 13종의
레이아웃을 satori 용으로 **한 벌 더** 구현해야 하고, 두 구현은 반드시 어긋납니다.
지금 보고 있는 DOM 을 그대로 굽는 쪽이 **"미리보기 = 결과물"** 을 보장합니다.
라이브러리(`html-to-image`)는 **버튼을 누를 때** 받습니다 — 안 쓰는 사람의 첫 화면에
얹지 않습니다.

### ② 완성본 3벌

사람이 임장 결과를 남에게 보낼 때 하는 말은 대체로 셋 중 하나입니다.

| 벌 | 하는 말 | 장 구성 |
|---|---|---|
| **현장 그대로** | 가서 본 것과 느낀 것을 순서대로 | 표지 → 방문 정황 → 현장 체크 → 좋은 점 → 아쉬운 점 → 마무리 |
| **한 장 요약** | 결론과 점수만 빠르게 | 표지 → 종합 점수 → 요약 → 판정 → 마무리 |
| **데이터로 보기** | 내 기록 옆에 실거래 숫자를 나란히 | 표지 → 항목별 점수 → **실거래·시세** → 태그 → 마무리 |

누르면 색과 장이 한 번에 잡힙니다. **빌더는 없애지 않았습니다** — 아래에서 계속
손볼 수 있습니다. 이미 만들어 둔 것을 버리지 않습니다.

### ③ 노트 밖의 숫자 (관련 정보 추가)

새 장 **"실거래·시세"** — ㎡당 매매가 · 월간 변동 · 전세가율 · 월 거래건수.
사용자가 현장에서 볼 수 없는 값을 자기 기록 옆에 놓습니다.

지킨 것 넷:

- **못 읽으면 그 장이 통째로 빠집니다.** 카드는 공유되는 이미지라 한 번 나가면
  되돌릴 수 없습니다 — 빈 숫자를 그리는 순간 그 카드가 곧 거짓 주장이 됩니다.
- **값마다 기준 시점**을 붙입니다. 지역 통계는 공표 주기가 달라 "지금"이 아닙니다.
- **출처를 카드 안에 찍습니다.** 숫자만 남고 근거가 빠지면 그때부터 주장입니다.
- **지역 단위임을 숨기지 않습니다** — "강남구 기준" 처럼 적습니다. 단지 값이 아닙니다.

## 3. 확인한 것

| 무엇 | 방법 | 결과 |
|---|---|---|
| 프리셋이 없는 테마·장을 가리키지 않는가 | 단위테스트가 CARD_THEMES·CARD_FRAMES 와 대조 | 통과 (처음엔 `market` 장이 없어 실패 → 그래서 만들었다) |
| 세 벌이 서로 다른 얼굴인가 | 테마·장 구성 중복 검사 | 3벌 전부 다름 |
| 숫자 없을 때 장이 빠지는가 | 단위테스트 3건 | rows 0건·null 둘 다 빠짐 |
| 전체 게이트 | `npm run build` | 통과 · 단위 514건 · 번들 전 구간 통과 |

## 4. 아직 안 한 것 — AI 문구 구성

소유자 지시의 **"AI가 그 디자인에 적용"** 부분은 이번 판에 넣지 않았습니다.
지금 카드에 들어가는 글은 전부 **사용자가 쓴 문장 그대로**입니다.

미룬 이유는 순서 때문입니다. AI 가 쓴 문장이 카드에 실려 공유되면, 그 문장은
**사용자 이름으로 밖에 나갑니다.** 그러려면 (1) 사용자가 나가기 전에 보고 고칠 수
있어야 하고 (2) AI 가 쓴 부분임이 카드에 표기되어야 하며(이 저장소의
`[AI 서술]` 규칙) (3) 재료가 모자랄 때 지어내지 않아야 합니다.
그 셋을 갖춘 흐름을 다음 판에서 붙입니다 — 카드가 먼저 나가야 그 흐름을 붙일
자리가 생깁니다.
