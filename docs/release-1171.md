# 1171 — 단지 분석 4종 탭 · 일정에 관심 단지 붙이기

소유자 2026-11-12 "추가로 기능 업데이트" · "고도화도 같이" · "모든 페이지 대상으로". AI 분석 통합은 앞서 정한 방향(도구별 횟수는 그대로 · 한 화면 탭)대로다.

## 바뀐 것
- AI 분석: 종합 진단 · 시세 예측 · 매수 타이밍 · 임장 동선 머리 아래에 탭 한 줄. 단지를 고른 뒤 탭을 누르면 그 단지를 들고 옆 도구로 간다(다시 고르지 않는다). 도구마다 실행 횟수는 예전대로 따로 센다.
- 모임 일정 만들기: "볼 단지"를 내 관심 단지에서 고른다. 고르면 일정 이름이 "○○ 임장"으로 채워지고, 일정 카드에 "단지 보기"가 붙는다.

## 하지 않은 것
- "모든 페이지 대상" 고도화는 이번 묶음에 다 들어가지 않았다. 이번에 손댄 화면은 AI 분석 4종과 모임 일정이다.
- 탭은 화면을 옮겨 가는 방식이다. 세 결과를 한 화면에 나란히 띄우는 것은 아니다.

- 로컬에는 단지 자료가 없어 "단지를 고른 뒤 탭 이동"은 주소 규칙을 시험으로만 확인했다. 운영에서 한 번 눌러 확인 필요.
