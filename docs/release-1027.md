# 1027 — 지도(위성·지적편집도 · 정비사업 걸러 보기) · 정비사업 구역 상세 · 제안서 "먼저" 묶음

소유자(2026-10-03): "관련해서 홈페이지 개선작업을 해서 파일과 코드를 알려줘, 그리고 변경 전, 후의 이미지도 보여줘" — 재개발닷컴에서 가져올 기능 엄선 10 과 「추가 개선 제안 30」 논의 직후. 제안서의 결정 칸이 비어 있어 "먼저" 로 적은 묶음과 지도·정비사업 기초 공사를 했다.
같은 날 추가 지시: "뉴스 화면에서 언론사 사진은 그대로 넣어줘" → 제안 21(언론사 사진 빼기)은 하지 않는다. 뉴스 사진 코드는 손대지 않았다.

기준: 1026g(tree 39fb6543). 바뀐 파일 116개(새 파일 24 · 삭제 2).

## 지도 `/map`
- **첫 화면**: 목적지 없이 열면 서울시청 · 축척 10(시·군·구 탭). 예전에는 전국 인기 단지 30곳 좌표의 평균(충북 진천 골프장)에서 단지 줌으로 열려 마커가 0개였다. `lib/map/home-view.ts`.
- **바탕 지도**: 필터 패널 "지도 레이어"에 `일반 / 위성` 과 `지적편집도`(따로 켜고 끔). 주소에 남는다(`base=sat`, `layers=…,cadastral`) — 공유받은 사람도 같은 바탕. NaverMap 이 이미 받던 `mapType`·`nativeLayers.cadastral` 을 /map 만 안 넘기고 있었다.
- **정비사업 걸러 보기**(레이어를 켰을 때): 사업종류 4묶음(민간주도·공공주도·소규모·기타) · 진행단계 7 · 이름표(구역명 / 진행단계 / 세대수). 칩의 숫자 = 그 칩을 눌렀을 때 보이는 구역 수. 받아 오기 전에는 "불러오는 중", 0곳인 칩은 흐리게. "전체 초기화"가 이 조건도 푼다. 조건에 맞는 구역이 화면에 없으면 안내 + "조건 풀기".
- **안내창**: 구역명·주소·출처를 이스케이프하고 출처 링크는 http(s) 만. "구역 상세 ›" 링크. /map 과 /redevelopment 가 한 빌더를 쓴다(`lib/redevelopment/map-layer.ts`). 노트·월세 비중·학교·역·공매·입주 안내창도 같은 이스케이프.
- **우하단 범례**: 정비사업 종류 범례가 "+ 매물 등록" 버튼 왼쪽을 덮던 것 → 버튼 아래에 머문다. 폰 범례에도 종류 색 풀이.
- **줌 캡션**: 탭마다 글자로 박아 둔 9·12·15 → 지금 지도의 실제 줌.

## 제안서 "먼저" 묶음 (번호 = 「추가 개선 제안 30」)
- **1 신고가 글의 "직전 3년"**: 가진 실거래가 3년에 못 미친다. 새 글은 줄마다 그 단지·면적대 이력의 첫 달을 적는다("2025.06 이후 최고"). "26평형" → "전용 26평"(전용 ÷ 3.3 인데 "평형"은 공급면적 기준이라 한 체급 작게 읽혔다). 지난 글 37건은 DB 에서 고쳤다.
- **2 AI 분석의 고정 예시 표**: 고른 단지·지역과 무관한 예시 표 3개(리스크 블록 · "강남구 BUY 강도 82" · 경제 지표)를 엔진에서 걷었다. 외부 모델에는 아는 값만 넘긴다. 예시 숫자를 그대로 내주던 `/api/economy/monitor` 와 계약 파일 삭제. 프롬프트 버전은 서버가 찍는다(v3). 숫자 검증의 허용 목록 = 입력 · 서버 참고 데이터 · 공공데이터.
- **4 보낼 수 없는 이메일 칸**: 검색 0건 카드의 "(선택) 열리면 알림 받을 이메일 · 열리면 알려주세요" → "빠진 단지 제보 · 제보하기". 받는 쪽도 주소를 저장하지 않는다.
- **5 "이 지역 알림 받기"**: 알림함만 열던 링크 → 누르면 그 지역이 구독된다(`app/components/RegionAlertButton.tsx`). 적힌 알림 종류를 실제로 오는 것(청약 공고(시·도 전체) · 새 등록 매물)으로. 면적대별·시세타이밍·온도·갭 · /region · AI 매수 타이밍. 경제지표 모니터는 "기준금리 알림 걸기"(누르면 아래 기준금리 알림 칸으로).
- **11 실거래 이력 채우기**: 1회 160곳은 크론 예산 240초를 넘겨 7회 중 4회가 "시간 초과"였다 → 1회 45곳 · 하루 6회(≤ 1,620회/일, 1025 때 총량 1,920 아래).
- **20 공유 그림**: 화면이 `openGraph` 를 직접 적으면 루트의 기본 그림이 사라진다 → 그림 없는 화면 24곳에 기본 공유 카드를 명시. 뉴스·이야기는 사진이 있으면 그 사진, 없을 때만 기본 그림.
- **22 0건 화면**: `/data/records`(11개 자료 전부 "연동 대기"·0건)를 사이트맵에서 빼고, 0건인 동안 색인 제외. 읽기에 실패한 것과 0건은 구분한다.
- **23 주소 정리**: 단지 비교 주소의 한쪽이 사라졌으면 남은 단지로 307(임시) · 992 에서 보관한 `/notes/templates` 링크 삭제.
- **27 오류 화면**: 구역 오류 화면(8곳 공통 몸체)도 화면 파일을 못 받은 오류면 한 번만 새로고침.
- **28 오류 기록**: 브라우저 스택(주소의 쿼리는 지움) · 오류 이름 · 빌드 표식(커밋 앞 7자, `<meta name="nz-build">`) · 경로. 탭이 받은 빌드와 서버의 빌드를 나란히 적는다.
- **29 가입 1단계 지표**: 화면이 열릴 때가 아니라 사람이 처음 움직인 뒤(누름·키·터치·휠) 세션당 한 번, 브라우저 계열과 함께.
- **30 DB 경고**: `market_agg.addr_dong` 의 search_path 고정 · 안 쓰는 `search_complex_facets` 실행 권한 회수.
- **21 뉴스 언론사 사진 빼기**: **하지 않음**(소유자 2026-10-03: 그대로 둔다).

## 고치다 발견한 것
- **지도 링크의 축척**: 지도는 주소에 네이버 줌(`z=16`)을 쓰는데 읽을 때는 축척(level)으로 읽었다 — 노트의 "지도에서 보기"(z=16)가 전국 화면으로 열렸다(운영 확인). `21 − z` 로 한 번 바꿔 읽는다(`lib/map/entry-params.ts`).
- **지역 알림이 오지 않던 경우**: 새 매물 알림은 구독 값("서울 강남구")과 매물의 지역("강남구") 표기가 달라 맞지 않았다. 구독 값은 한 표기로 저장하고(시군구 코드 표 기준), 청약 공고는 시/도로, 매물은 시군구·시/도 후보로 맞춘다. "대구 달서구"가 "서구"에 걸려 인천 서구 숫자가 나오던 부분 일치도 정확 일치로. `lib/alerts/region-value.ts`.
- **온도 라벨 "인천 인천 중구"** → "인천 중구"(코드 + 쌓인 행 10건).
- **지도 인증이 실패한 주소에서 화면이 통째로 오류 화면**: 네이버 지도 인증이 실패하면 SDK 가 지도·마커 안쪽을 비우고, 그 뒤 정리 호출(`marker.setMap(null)`)이 던져 정비사업 지도에서 "목록" 탭을 누르거나 지도에서 나가는 순간 오류 화면이 됐다(검증 서버에서 재현). 인증 실패 때 참조를 놓고, 정리 호출을 감쌌다(`components/map/NaverMap.tsx`).
