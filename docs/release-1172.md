## 바뀐 것
- 지도 마커 · 말풍선(구 · 단지 · 공매 · 청약)의 글꼴을 `sans-serif`에서 사이트 글꼴(--font-sans)로 바꿨다.
- 같은 곳의 11px 글자(19곳)를 사이트 글자 크기 단계인 12px로 올렸다.
- 회색 고정색(#888 · #444)을 테마 색(--text-3 · --text-2)으로 바꿔 어두운 테마에서도 맞춘다.

## "자세히 알아보기" 칸
