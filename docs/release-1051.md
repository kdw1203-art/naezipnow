## 1. 배포 막힘 해결 — 노트 상세 용량

- 노트 상세의 댓글 · 음성 메모 도구 · 가입 배너를 **따로 받는 청크**로(NoteLazyParts — 1043 독자 평가 NoteRatingLazy 와 같은 방식). 서버 렌더는 그대로(첫 HTML 에 댓글이 있다).
- 번들 예산 검사에 **여유 경고**: 상한까지 2.5KB 안쪽인 라우트를 실패가 아니라 경고로 적는다(소수점 실측). Vercel 이 로컬보다 크다는 사실을 주석에 남겼다. 예산은 올리지 않았다.
- 결과: /notes/[id] 495.2KB → **484.3KB**(여유 10.7KB).

## 2. 홈 실시간 토론

- 홈 맨 아래(동네이야기 다음 · 전폭) "실시간 토론" 칸 + 전체 화면 `/talk`(색인 안 함 — 서버 HTML 에 본문이 없는 화면).
- 왼쪽: 탭 **토론 많은 · 상승 · 하락 · 거래량** — 수도권(서울 25개 구 + 경기·인천) 지역 순위.
  숫자는 적재된 것만: 한국부동산원 매매가격지수 전월비(홈 구별 막대와 같은 계산) · 한국부동산원 매매 거래량(홈 지역 동향 카드 "8월 거래 180건 · 부동산원"과 같은 행 — 처음엔 국토교통부 신고 건수로 했다가 같은 화면에서 강남 80건 · 180건으로 갈려 바꿨다) · 최근 7일 글 수.
  값이 없는 지역은 그 탭에서 빠진다(0 으로 세우지 않는다). 글이 하나도 없으면 처음 탭은 "상승".
- 오른쪽: 고른 지역의 **사람 글(최신 순, 위)** + **자동 소식('소식' 표시, 아래)** — 지수 · 거래 · 지역 뉴스 제목(최근 3주 · 1048 시장 신호와 같은 지역 낱말 규칙) · 그 지역 공개 임장노트.
  사람 글이 없으면 맨 위에 "사람 글 없음 · 아래는 자동 소식". 지어낸 글은 없다.
- 한 줄 쓰기(로그인): 200자 · **단지 붙이기**(선택 · 그 지역 단지만 — 기존 검색 제안에서 고르고 서버가 단지 id 를 해독해 지역을 다시 확인) ·
  금칙어(커뮤니티 글과 같은 필터) · 같은 글 24시간 금지 · 10분 10줄 · 계정당 분당 5건. 내 글은 지우기, 남의 글은 신고(한 사람 한 번 · 3건이면 숨김).
- 보이는 동안 30초마다 새 글을 받는다(다른 탭·화면 밖이면 멈춤). 판 코드는 홈이 화면 가까이 오면 받는 청크 — 홈 첫 로드 번들에는 얇은 로더만.
- DB: `region_talks`(한 줄 · 지역 · 단지 · 작성자 · 숨김/지우기) · `region_talk_reports` · `report_region_talk()` — service_role 전용(RLS on · 정책 없음 · anon/authenticated 권한 회수). 회원 탈퇴 시 파기 대상.

## 3. 단지·지역 화면 시간 초과 — 한 번 자동 재시도

- 서버 렌더 오류(digest 있음)로 오류 화면이 뜨면 /complex/·/region/ 에서는 2.5초 뒤 **한 번만** 저절로 다시 받는다(같은 주소 2분에 한 번). 그 사이 문구 "다시 불러오는 중 · 잠시만". 두 번째 실패면 지금 화면 그대로.
- 원인(몇 초짜리 DB 포화)은 그대로 — 조회 자체는 평시 15ms(코드 주석 실측). 포화 원인 조사는 "남은 것".

## 4. 폰 광고 스크립트 지연

- 폰 첫 진입: 예전 `load` → idle(최대 4초) → 지금 `load` → **첫 스크롤·터치·키 입력 또는 6초** → idle. 데스크톱은 그대로 즉시.
- 근거: 오늘 Lighthouse 모바일(홈) — 광고 스크립트를 막으면 TBT 4,510 → 3,180ms(FundingChoices 724ms + DoubleClick 577ms). 폰 광고 칸은 첫 화면 아래라 보이는 시점은 같다.
