## 다른 사이트에서 가져온 것 4가지
네이버 부동산 · 호갱노노 · 아실의 화면은 이 작업 환경에서 열 수 없었다. 국토교통부 발표 요약 · 앱 소개 · 이용 안내 글로 확인했고, 화면을 본뜬 것은 없다.
- **13 직거래 · 등기 표시**: 최근 실거래 표의 비고에 "직거래" · "등기" 배지, 추이 머리의 최근 실거래 · 신저가 날짜 옆에 "직거래". 국토교통부 거래유형 · 등기일자(우리 자료에는 2026년 계약분부터). 표식은 계약월 · 일 · 금액 · 면적 · 층이 같은 거래에만 붙는다(`lib/complex/deal-marks.ts` · `getComplexDealMarks`). **대표가 · 신고가 · 신저가 계산은 그대로**(직거래를 빼지 않았다).
- **14 신고가 대비 %**: 최근 실거래가 아래 "▼36.0% 신고가 대비". 같은 평형의 조회 기간 최고가와 견주고, 같거나 높으면 표시하지 않는다(`belowHighPct`).
- **15 청약 표**: "084.9890A" → "84㎡A" · "(△1)" → "미달 1세대" · "3.60" → "3.6 : 1" · "-" → "—" · 지역 옆에 순위("1순위"). 꼴이 다르면 원문 그대로(`lib/applyhome/normalize.ts`).
- **16 N년차**: 단지 상세의 준공 칸 "준공 · 19년차". 준공한 해가 1년차(`builtYearsLabel`).
