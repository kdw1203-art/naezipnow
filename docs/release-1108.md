## 3. 단지 상세(A안 + B 표 규율 + C 인근 단지)
- **기록 한 자리** — "이 단지 임장노트" 카드 · "거주민 후기" 카드 · "단지 토론" 섹션 → `{단지} 기록` 머리 하나 + 칩(임장노트 N · 거주민 후기 · 토론).
  임장노트는 서버 HTML(색인), 후기 · 토론은 칩을 누른 뒤에만 청크를 받는다(예전엔 스크롤만으로 셋 다 받았다). 쓰기 단추는 outline 하나.
- **인근 단지 + 단지 비교 = 한 목록** — 상대 단지 줄에 연식 · 세대 · 최근 6개월 신고 건수(매트뷰 열 하나 더 읽음 · 비용 0)와 "비교" 단추(조합이 있을 때만).
  목록에 없는 상대는 아래 칩(링크 손실 0). 폰 블록 · 데스크톱 레일 같은 조각.
- **AI 입구 하나** — 결과 요약 머리의 "이 단지 AI 종합 진단 받기" 하나(예전엔 임장노트 카드 안 "AI 분석" 소제목 + 단추가 하나 더).
- **국토부 실거래 이력** — 본문 중간 카드 한 장 → 최근 실거래 표 아래 링크 한 줄.
- 관련 기사는 "동네" 묶음 첫 자리로(자동수집 기사 — 1044 분리 유지). 아래쪽 순서: 실거래 → 분석 → 전월세 → 기록 → 동네(기사 · 인근 · 정비 · 입주 · 전문가) → 읽을거리(2 · 2) → 출처.
