# 1173 — 광고 칸 크기 고정(좌우 160×600 · 본문 336×280)

소유자 2026-11-12 "자세히 알아보기 칸 크기 · 글씨 조절" → 칸 크기 고정으로 결정.

## 바뀐 것
- 좌우 띠: 넓은 화면에서도 160×600으로 고정(예전 300×600). 소유자가 만든 애드센스 "수직형" 단위(8506807172)를 기본으로 쓴다.
- 본문 · 옆 열 광고: 형식을 Google 에 맡기던 것(auto)을 336×280 고정으로. 폰 폭이 380px 미만이면 300×250.
- 홈 광고 칸(AdSenseUnit)도 같은 336×280.
- 1172(지도 말풍선 글꼴 · 크기 통일) 포함.

## 알아 둘 것
- 광고 안 글자는 Google iframe 이라 바꿀 수 없다. 칸 크기만 정했다.
- 어떤 광고(이미지 · 글자 목록)를 넣을지는 Google 이 정한다. 고정 크기에서는 이미지 광고가 들어올 때가 많지만 목록형이 다시 나올 수 있다.
- 글 끝 전용 단위(인아티클)를 따로 지정하면 그 자리는 예전처럼 유동형으로 나간다(지금은 지정 없음).

## 확인
- 단위 시험 2,673 통과 · 전체 빌드 통과 · 변경 전후 이미지 2장(전 = 운영, 후 = 로컬 · 점선이 광고 칸 크기).
