# 1141 — 회원 조회 · 메뉴 옆 대기 숫자 · 모바일 메뉴 묶음 · 인증 링크 안내

50가지 제안 중 코드로 할 수 있는 것 1차(13 · 41 · 42 · 43 · 44 · 11).

- /admin/members(신규): 가입 회원 최근 50명 · 이메일/이름 검색 · 기본 정보 통계(연령대 · 시·도 · 직업 · 보유 주택 · 이용 목적). 개인정보는 줄여서 보인다(생년월일 → 연령대 · 휴대전화 가운데 가림 · 주소 시·구까지). users 권한.
- 메뉴 옆 처리 대기 숫자: 신고 · 문의 · 매물 검수 · 전문가 심사 실집계. 0 이거나 못 읽으면 숫자 없음. 접힌 묶음에는 "N건 대기".
- 모바일 관리자 메뉴: 23개를 한 줄로 밀던 것 → 윗줄에서 묶음을 고르고 아랫줄에 그 묶음 화면만.
- 로그인 화면: 인증 링크를 다시 눌렀을 때 "이메일 인증 실패" → "인증 링크 만료 또는 이미 사용됨 · 인증을 마쳤다면 아래에서 바로 로그인".
- docs/email-templates-ko.md: 인증 · 비밀번호 재설정 메일 한국어 문구(소유자가 Supabase 에 붙여 넣는다).

확인: 빌드 통과 · 단위 테스트 2,636. 회원 화면은 자료 없는 로컬에서 실패 표시만 확인 — 운영 자료로는 적용 뒤 확인.
