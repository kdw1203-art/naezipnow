# release-1204 · 홈 빈 공간 없이 — 폰 · PC 배치 구분

소유자 요청(2026-11-21): "빈공간이 많아보이는데 모바일용, 웹사이트용 페이지 구분해서 반영해주고 빈공간없도록".

원인 셋: ① 둘째 줄 세 칸이 열마다 따로 쌓여 짧은 열 아래가 실시간 토론까지 통째로 비었다 ② 값 없는 칸("지역 동향 없음" · "최근 기사 없음" · "실거래 없음")이 자리만 차지 ③ 광고 칸(1201 · 1203 에서 접힘 처리).

- **PC(1024px~)**: 둘째 줄을 한 흐름으로 — CSS 다단 3열이 열 높이를 맞춰 채운다(카드는 쪼개지지 않음). **태블릿** 2열. **폰** 한 줄로 쌓기(12px 간격). DOM 순서 = 읽는 순서.
- **값 없는 칸은 홈에서 그리지 않는다**: 지역 동향(0건 · 실패), 실거래 금액 순위(0건 · 실패), 동네이야기 · 뉴스룸(실패 · 둘 다 0건 — 뉴스 0건이면 뉴스 칸만), 공개 임장노트(실패). 각 화면(지도 · 뉴스룸 · 동네)이 그대로 맡는다.
- **지도에 찍을 값이 없으면** 지도 칸 대신 숫자 칸 · 오늘의 시장이 첫 줄을 나눠 쓴다.
- **폰 실시간 토론**: 순위 목록 230 → 184px · 글 칸 460 → 300px(폰 한 화면 반을 차지하던 것). PC 그대로.

- **폰 푸터 컴팩트**(소유자 "더 작고 컴팩트하게"): 2열 세로 목록 → 묶음마다 제목 한 줄 + 링크를 옆으로 흘려 접기 · 위아래 여백 축소. PC 4열 그대로. 사업자 고지 · 약관 링크는 그대로(법정 고지).
- **운영 콘솔 경보 해소 버그**: 수집 점검 서명이 콜론으로 이어져(`ingest:applyhome:error_unrecovered` · 회복 `ingest:applyhome:recovered`) 회복 기록이 경보를 닫지 못했다 → `…:recovered` 가 같은 소스의 모든 경보를 닫는다(lib/admin/health-alerts-fold.ts okCovers · 테스트 추가). applyhome 은 11-21 00:40 회복분이 이제 "해소"로 보인다.
- **ops.cron_job**: 1201 의 크론 고침(2분 끊김)을 정규 스케줄로 한 번 돌려 확인 → 경보 해소(아래 실행 기록).

- **홈 첫 줄 빈칸**: 숫자 칸 ↔ 내 화면 칸 높이를 시세판에 맞추고(내 화면은 같은 높이 안에서 스크롤) · PC 지도가 첫 줄 높이를 다 채운다(최소 440px).
- **관리자 빈 띠 배너 자리**: 점선 큰 상자 → 오른쪽 한 줄 글자.
- **바탕 지도 넷**(소유자 "지형도 말고 일반지도도 · 위성이랑 겹쳐보기"): 일반 · 위성 · 겹쳐보기(위성 + 지명) · 지형 — 정비사업 지도 · 통합 지도. 정비사업 지도의 지적편집도(용도지역 색)는 기본 끔(단추로 켬). 예전 base=sat 링크는 겹쳐보기로 그대로 열린다.
- **1기 신도시 구역 표시**(소유자 "1기 신도시 등 정비사업 현황 구역표시를 지도에도"): 선도지구 13 · 2차 후보 9곳 — 공식 경계 도형이 공개 자료로 없어, 구역 단지 102곳의 실제 좌표(complex_geocode)를 단지마다 70m 넓혀 감싼 **근사 범위**를 그린다(`/api/redevelopment/newtown-shapes` · 하루 캐시). 진행 단계 색으로 칠하고 범례에 "단지 위치로 그린 근사(공식 경계 아님)".
