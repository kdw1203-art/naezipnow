# 1155 — 정비사업 지도를 지적도와 함께

소유자 2026-11-11 "지적도를 참고해서 재개발닷컴의 지도처럼 보일 수 있게".

## 바뀐 것
- `/map`: 정비사업 레이어를 켜면 지적도(필지 경계)가 함께 켜진다. 지적도는 따로 끌 수 있다.
- `/redevelopment` 지도: 지적도를 기본으로 켜고 끄는 단추를 뒀다. "점은 대표 지번 위치 · 구역 경계 아님" 한 줄.
- 1153 · 1154 포함.

## 하지 않은 것 — 구역 경계선(다각형)
- 자료는 있다: 서울 열린데이터광장 「서울시 의제처리구역 위치정보」(OA-20957 · SHP · 연 2회) · 국토교통부 「도시및주거환경정비 정비구역」(공공데이터포털 15146864 · SHP).
- 둘 다 공공누리 4유형(출처표시 · 상업적 이용금지 · 변경금지)이라 구독 · 광고가 있는 서비스에 그대로 싣지 않았다. 이용 허락을 받으면 싣는다.
