# 1044 — 뉴스 · 동네글 분리(메뉴까지)

소유자 지시(2026-10-06): "뉴스랑 동네글을 분리해줘". 범위를 물었고 답은 **"메뉴까지 분리"** —
동네 화면에서 뉴스 줄을 빼는 것에 더해, 상단 메뉴에 뉴스를 따로 두고 동네 카테고리 줄에서 뉴스룸 칸을 뺀다.
1043 위에 누적. 가격·상품 변경 없음. DB 변경 없음. 주소 변경 없음.

## 1. 메뉴

| | 예전(1043) | 지금 |
|---|---|---|
| 상단 메뉴 | 임장노트 · 지도 · AI 분석 · 동네 · 요금제 | 임장노트 · 지도 · AI 분석 · 동네 · **뉴스** · 요금제 |
| 동네 하위 | 동네이야기 · 뉴스룸 · 청약 · 정비사업 | 동네이야기 · 청약 · 정비사업 |
| 뉴스 하위 | — | 뉴스룸 · 주간 다이제스트 |
| 켜지는 메뉴(뉴스 화면) | 동네 | 뉴스 |
| 폰 하단 탭(뉴스 화면) | 동네 탭이 켜짐 | 어느 탭도 켜지지 않음(AI 분석·요금제 화면과 같다) |

- 상단 메뉴 · 폰 전체 메뉴 · 왼쪽 가장자리 메뉴는 한 목록(`app/components/nav-data.ts`)을 읽는다 — 세 곳이 같이 바뀐다.
- 폰 하단 탭 다섯(홈 · 지도 · 기록 · 동네 · 마이)은 그대로다. 뉴스 자리는 없다 — 폰에서 뉴스는 ☰ 전체 메뉴 · 홈의 뉴스룸 칸 · 검색으로 간다.
- 주소는 옮기지 않았다(`/town/news` · `/town/news/[id]` · `/digest`). 색인 · 공유 링크 · 사이트맵 그대로.
  주소가 `/town` 아래라 "어느 메뉴가 켜지나"는 **가장 긴 접두 하나**로 정한다(`navGroupOf`) — 예전 규칙(`startsWith`)이면 뉴스 화면에서 동네와 뉴스가 같이 켜진다.

## 2. 동네 화면 — 기사를 싣지 않는다

- **동네이야기(`/town`)**: "오늘의 뉴스" 줄(기사 6줄) 삭제. 카테고리 줄은 다섯 칸(동네이야기 · 청약 센터 · 공매 물건 · 입주 물량 · 정비사업 지도).
  이 화면은 이제 뉴스를 읽지 않는다(조회 1회 감소는 아니다 — 같은 조회를 피드가 쓴다).
- **동네 홈(`/town/[region]` 62곳)**: "○○ 뉴스" 칸 삭제 → 이웃 글이 한 단 전체를 쓴다. 제목 · 설명 · 머리 한 줄에서 "뉴스"를 뺐다
  (`강남구 동네 홈 · 이웃 글 · 시장 요약`). 시세 타일 · 인근 지역 막대 · 공개 임장노트 · 다른 동네 홈은 그대로.
  "이야기 피드 ›" 링크의 죽은 쿼리(`?kind=post` — 1043 에서 유형 칸이 없어졌다)도 뗐다.
- 지금 운영에는 이웃 글이 0건이다. 그래서 동네이야기는 "이웃 글 없음 · 첫 이야기 쓰기" + 동네 홈 바로가기 + 동네 홈 전체로 열린다
  (뉴스 줄이 화면을 채워 주던 것이 없어진다 — 지어내지 않는다).

## 3. 뉴스 화면 — 제 머리

- **뉴스룸(`/town/news`)**: 머리 아래의 동네 카테고리 줄 삭제 · 빵부스러기 "동네이야기 › 뉴스룸" 삭제(대분류 첫 화면 — 동네이야기 · 임장노트 첫 화면처럼 두지 않는다).
  머리 모양은 1043 그대로다(공용 `PageHead` — 아이콘 칩 · 제목 · 한 줄 · "주간 다이제스트" 버튼). 문구는 `app/town/news/NewsHead.tsx` 한 곳.
  순서: 머리 → 주제 칩 → 목록.
- 로딩 화면도 같은 머리를 그린다(예전 스켈레톤은 1006 의 마스트헤드 상자라 로딩이 끝나면 머리 모양이 바뀌었다).
- 주간 다이제스트(`/digest`): 빵부스러기 "뉴스룸 › 주간 다이제스트" · 불러오기 실패 때 버튼 "뉴스룸 보기".
- 뉴스 상세 · 주제별 화면은 빵부스러기가 이미 "뉴스룸 › …"였다 — 켜지는 메뉴만 동네 → 뉴스로 바뀐다.

## 4. 같이 고친 틀린 문장

- 뉴스 상세 오른쪽 "○○ 임장노트" 칸: "공개 노트는 동네이야기 피드에 실림" → "공개 노트는 임장노트에 실림"(1043 부터 사실이 아니었다).
- 원룸·오피스텔 화면(`/rent/[region]`) 오른쪽 칸 제목 "동네이야기 · ○○" → "○○ 관련 화면"(줄에 뉴스룸 · 시장 데이터가 같이 있다).

## 5. 손대지 않은 것

- 홈의 "동네이야기 · 뉴스룸" 두 칸 — 이미 따로 선 카드다.
- 뉴스 상세 끝의 "이 기사로 동네이야기 쓰기 ›" — 기사에는 댓글이 없어 의견을 쓰러 가는 길이다(섞어 보여 주는 것이 아니다).
- 정비사업 지도의 관련 기사 줄 · 404 화면의 바로가기 칩 · 검색 결과(이야기와 뉴스는 원래 다른 묶음).
- 저장: 이웃 글과 기사는 같은 표에 있고 자동수집 표시(`is_automated`)로 가른다 — 화면 분리와 무관해 그대로.
- 동네 홈의 "'○○' 새 소식 알림" 버튼 — 알림 구독이다(기사 목록이 아니다).
