## 홈
- 검색 띠 "바로 보기" 칩(강남구 · 마포구 …)과 아래 "지역 · 단지 바로가기"의 지역 줄이 같은 목록 → 칩 하나로(지역 종합 화면 /region 으로 · 지도는 옆 "지도에서 내 동네 찾기").
  바로가기 칸은 "최근 6개월 거래 많은 단지"만.
- 지역 동향 아래 "서울 25개 구 막대(최고 · 최저)"는 아래 실시간 토론의 지역 순위(지수 전월비)와 같은 값 → 삭제.

## 지역 종합(/region/[id])
- "최근 실거래 5건" 칸 삭제 — 단지별 현황(최근 거래순 · 가장 최근 신고 1건)의 첫 줄들과 같은 거래(운영 캡처). 머리 아래 "최근 실거래 N건" 보조 링크도 함께.
  가장 최근 신고 한 건은 Q&A 에 남는다.
- "요약 문장"(머리 · 그래프 · 표가 말한 수를 다시 적는 글)은 닫힌 접힘으로 — HTML · 검색 인용 문장은 그대로.
