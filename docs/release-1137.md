# 1137 — 홈 개편: 시세판 ↔ 내 화면 번갈아 보기

선택안: B(시세판) + C(내 화면)를 한 자리에서 번갈아 보여 주기.

- 비로그인: 지금처럼 시세판만 보인다(탭 없음).
- 로그인: 상단에 "시세판 / 내 화면" 탭. 9초마다 자동으로 넘기고, 탭을 누르거나 판 위에 마우스·포커스가 오면 멈춘다. 동작 줄이기 설정이면 자동 넘김 없음.
- 두 판은 한 칸에 겹쳐 있어 넘길 때 아래 내용이 들썩이지 않는다. 안 보이는 판은 inert(키보드·스크린리더 제외).
- 내 화면: 바로 가기 4칸(내 임장노트 · 관심 단지 · 관심 지역 · 내 분석) + 관심 지역 요약 · 관심 단지 요약 · 활동 카드 · 최근 본 단지. 기록이 하나도 없어도 바로 가기는 늘 보인다.
- 시세판이 비어 있으면(수집 첫날 · 대표 지역 없음) 탭을 숨기고 내 화면만 보여 준다. 빈 판으로 넘어가지 않는다.
