# 991 — 개편 1판: 홈 단일 트리 · 탭바 · 가입 퍼널 · 결제 완주

근거 문서: `docs/proposal-991.md` (30일 실측 + 코드 전수 조사). 이 판은 그 계획의 첫 주 분량이다.

## 한 줄

**아이폰 홈 반응 지연의 구조적 원인(이중 트리)을 없애고, 가입·로그인·결제에서 "왜 안 되는지"를 화면이 말하게 했다.**

## 바뀐 것

### A2 · 홈 — 트리 하나, 블록 다섯 (`app/page.tsx` 1,102줄 → 375줄)
- 모바일 트리(290줄)·데스크톱 트리(412줄) 이중 렌더를 **한 트리**로. 같은 컴포넌트 13개를 두 번 마운트하던 구조가 사라졌다.
- 비로그인 첫 화면 = ① 검색 ② 오늘의 시장 한 문장 ③ 공개 임장노트 3장 ④ AI 입구 ⑤ 지역 시세. 로그인이면 ⑥ 내 관심.
- 내린 것: 시세 티커 · 슬로건 띠 · 미니지도 · 도구 추천 · "더 알아보기" 8링크 · 동네이야기 입구 · 출석/미션 카드 · 레벨 KPI(전부 `/my` 에 있다).
- 첫 화면에 `rise-in`·`data-reveal` 없음 — 정적이다.
- `/page` 번들 486KB → **451KB**.

### A3 · 탭바·메뉴
- 탭바 '동네' → **'분석'** (`/analysis` 62회·251초 vs `/town` 31회·7초). 계산기·에이전트도 분석 탭이 켜진다.
- 전체 메뉴 43링크 → **12**. GNB 드롭다운 18 → 8.
- `tabBarActive()` 셋째 인자는 이제 "이 탭을 함께 켜는 경로"다(동네 전용 규칙 제거).

### A6 · iOS 반응 지연
- `ViewportGroupTracker` 삭제 — 30일 5,198건/6명. iOS 주소창 접힘마다 resize → fetch. `lib/analytics/viewport-context.ts`·`gtag-mirror.ts` 도 함께(참조 0).
- 반응형 QA 게이트는 삭제 사실을 PASS 로 적고, 발신부가 되살아나면 WARN.

### C4 · 가입 퍼널
- `/welcome` 온보딩 **5단계 → 1단계**(관심 지역). 예산·목적·페르소나·기본 정보는 첫 노트 전에 답할 이유가 없다. 완주 판정·200P 는 서버 실데이터 기준이라 바뀌지 않는다.
- 로그인 실패에 **이유**를 싣는다: `social_only_<provider>`(카카오·토스 sentinel 해시 / Supabase Auth providers=google) · `no_account` · 그 외 = 비밀번호 오류. 화면은 문구가 아니라 **행동**이 다르다 — 소셜 버튼 안내 / 가입하기 / 비밀번호 찾기(이메일 프리필). 틀린 뒤에만 진단하므로 성공 경로·속도 제한은 그대로.
- 가입 동의 행 3개를 40px 행으로(체크박스 16px 만 목표였다).

### C3 · 결제 완주
- 자동결제 카드 등록: 누른 순간·SDK 오류 코드·사용자 취소를 계측(`billing_auth_open/fail/cancel`, 카드 정보 없음). 등록 3건이 전부 `pending`(start 만 호출, register 미도달)인데 어디서 멈추는지 알 길이 없었다.
- 카드 등록창 열기 실패 시 error 화면으로 넘기지 않고 **같은 자리에서 다시 누를 수 있게**.
- `/payment/success` 첫 버튼: "마이 페이지에서 플랜 확인" → **"바로 AI 분석 시작하기"**.
- 단건 이용권의 "해지 요청" 버튼(고객센터 티켓) 삭제 — 단건은 해지할 것이 없다. 환불은 결제 내역의 환불·문의.

## 소유자 확인 사항
1. **카카오 로그인 키** — 가입 화면에 소셜 버튼이 Google 하나뿐이다(`AUTH_KAKAO_ID`·`AUTH_KAKAO_SECRET` 미설정). 코드는 이미 카카오·토스를 지원한다. 한국 서비스의 첫 버튼은 카카오여야 한다 — 이건 코드가 아니라 키다.
2. **자동결제 실결제 1건** — 이번 판부터 카드 등록창의 실패 이유가 기록된다. 등록을 한 번 끝까지 진행해 주시면 `pending` 이 왜 멈추는지 확정된다.
3. 배포 후 하루 뒤 `web_vitals` iPhone 홈 INP 를 본다.
