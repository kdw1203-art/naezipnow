# 1167 — 가입 3개월 · 전문가 1년 무료 이용

소유자 2026-11-12 "가입하면 3개월, 전문가 등록하면 1년 무료 이용" — 답: 가입은 프로 요금제 3개월 · 전문가는 프로 요금제 + 홍보 둘 다.

## 바뀐 것
- 가입: 새 계정에 프로 요금제(월 18,900원 상당) **90일 무료** — 이메일 · 카카오 · 토스 · Google 가입 모두. 결제는 일어나지 않고, 90일 뒤 만료 스윕이 무료 요금제로 돌린다.
- 전문가 인증 승인: 프로 요금제 **365일 무료** + 홍보 노출 **365일 무료**(100일 → 365일).
  - 가입 무료 기간이 남아 있으면 그 뒤에 이어 붙인다.
  - 자동결제 구독 중인 계정 · 다른 유료 요금제 계정은 건드리지 않는다(만료를 적으면 결제 중인 구독이 강등된다).
- 화면: 가입 화면 한 줄("가입 시 프로 요금제 90일 무료 · 자동 결제 없음") · 전문가 등록 화면의 기간 표기.
- 요금 · 상품은 그대로다(결제 심사 관문 통과).

## 알아 둘 것
- 이미 가입한 회원과 이미 승인된 전문가에게는 소급하지 않는다(새 가입 · 새 승인부터).
- 탈퇴 뒤 다시 가입하면 무료 기간을 또 받는다 — 막는 장치는 넣지 않았다.
- 가입 화면의 세 칸(임장노트 · 관심 단지 10곳 · AI 분석 누적 3회 무료)은 무료 요금제 한도 표기 그대로다.
- 프로 요금제 무료 기간 동안 AI 호출 비용이 는다.

## 확인
- 단위 시험 2,665 통과 · 전체 빌드 통과(요금 관문 포함) · 변경 전후 이미지(가입 · 전문가 등록).
