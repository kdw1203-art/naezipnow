## /journey — 노선도 + 지금 단계 하나
- 네이비 히어로 제거. lg 3열(250 / 본문 / 300). 왼쪽 레일: 진행 링 + 세로 노선도 6역(완료 초록 ✓ · 지금 주홍 링 · 예정 회색), 누르면 펼침+스크롤,
  저장 위치 한 줄. 폰: 링 + 한 줄 + 단계 칩 가로 레일.
- 가운데: 지금 단계만 펼침(네이비 2px 테두리), 나머지 한 줄 접힘(번호·제목·할 일 이름·펼치기). 완료 버튼 "이 단계 완료 → 다음: …".
- 오른쪽 레일: 다가오는 마감(계약잔금 일정표 상태에서 `buildContractTimeline`, 남은 것 3개 — 지난 날은 법정 기한 미체크만), 진행 중 신호, 일정표 입구.

## /journey/contract — 입력 한 판 + 핀 타임라인
- lg 2열(340 sticky 입력 / 타임라인). 입력: 날짜 2×2 · 금액 2×2 + 잔금 자동(읽기 전용) · 계약금 10% · 지급 막대 · ics(채움 파랑 1개)·인쇄·지우기 · 진행 카드.
- 다음 마감 띠(흰 카드 + 주홍 왼쪽 선 · 큰 D-day · "할 일 보기"는 그 그룹으로 스크롤). 타임라인 핀: 완료 초록 ✓ / 오늘·지난 법정 주홍 ! / 법정 노랑 ! / 돈 파랑 $ / 나머지 회색.
  모두 체크·지난(비법정) 그룹은 접힘, 인쇄 때 전부 펼침.

## /quiz — 좌우 대결판 + 답 뒤에 배우는 칸
- lg 2열(본문 / 300 레일). 대결판 한 카드: A | VS | B(md+ 좌우, 폰 세로), 사실 2×2, 큰 가격. 답 줄은 md+ 카드 안 고정, 폰은 탭바 위 sticky.
- 공개 카드(`QuizReveal`): 정답/아쉬워요 · 두 가격 막대 · 3.3㎡당 · 차이(Delta) · 준공·층 차이 · 단지 링크 · 다음 문제.
