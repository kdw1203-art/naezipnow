# 1074 — 페이지별 세부 ① 단지 비교 · 실거래 구간 · 단지 목록 + 전 페이지 손가락 표적·칸 넘침

1073 검토 문서(docs/design-review-1073.md) §4 계획의 두 번째 묶음. 소유자 선택 "공통 틀 + 페이지별 세부까지(여러 묶음)".
DB 변경 없음 · 가격·심사 문구 변경 없음 · 사실·수치·문구 삭제 0.

## 측정에서 본 것(1073 빌드, 폰 390 · PC 1280)

- **단지 비교**(/complex/compare): 폰에서 지역 칩 63개가 줄바꿈으로 쌓여 첫 화면 약 700px 을 덮었다. 지역 화면 링크 24px.
- **실거래 구간**(/tx/…/area/…): 단지 이름 40줄이 전부 밑줄 파란 글자, 폰 세로 히트 16px. 지역 목록(/tx)은 네 칸 줄에서
  "용인 수지구"처럼 띄어 쓴 이름이 두 줄로 접혀 칸 높이가 들쭉날쭉.
- **단지 목록**(/complex/browse): 구 칩 폰 31px. 링크 끝 화살표 "→"(사이트의 다른 링크는 "›").
- **24px 미만 표적**(문장 속 링크 제외, 전 페이지 폰): 81곳 — 단독으로 서는 글자 링크(자료실 6 · 알림 센터 · 수수료 안내 ·
  임장 가이드 단지 10 · 다이제스트 뉴스 · 노트 시장), 접기 단추 22px, 체크박스 12px, 오프라인 홈 20px.
- **칸 넘침**: 두 자리 순위(10~)가 폰 15px 칸 밖으로 3px(토론 47줄 · 임장 가이드).
- **읽는 폭**: 지역 요약 문단 한 줄 89자.

## 지킨 것

- 링크·목적지·순서·문구는 그대로(실거래 비교 63개 링크는 HTML 에 그대로 — 검색 색인 동일).
- 문장 속 링크는 밑줄 그대로(색만으로 링크를 알리지 않는다 — WCAG 1.4.1). 이번에 밑줄을 걷은 것은 표·목록의 이름 줄뿐.
- PC 레이아웃은 표 이름 줄 높이·칩 높이 그대로(`md:` 로 되돌림).
