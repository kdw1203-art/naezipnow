## 단지 분석 4종(/analysis/ai/ai-diagnosis · ai-prediction · ai-inspection · ai-timing)
- 공통: 머리(아이콘·제목·useCase·기준 시점 칩) → `lg:grid-cols-[minmax(0,1fr)_300px]`. 왼쪽 단지 줄 → **대표 그림** → 타일 4칸 → 근거·출처 → 다음 행동.
  오른쪽 레일 ① 내 조건(TuningForm, 재계산) ② 이 결과로(임장노트에 담기 · 관심 단지 · 비교 · 결과 링크) ③ 이어서 보기. 단지 고르기 전엔 도구별 **빈 틀**
  (레이더 축 · 부채꼴 축 · 지도 격자 · 회색 신호등) 위에 검색.
- 종합 진단 = 레이더 + 큰 점수 + 결론 알약 + 축별 근거 행 / 시세 예측 = 낙관·기본·비관 부채꼴 + N년 뒤 기본값 + 해마다 표 + 가정 / 임장 동선 = 번호 순서 목록
  (좌표·도보 시간은 데이터가 없어 생략) / 매수 타이밍 = 종합 결론 + 신호등 3카드(흐름선은 시계열 있을 때만).

## 지역 시세 4종
- 면적대별 실거래가: 통계 타일 5칸 + **면적 선반 5칸**(누르면 아래 상위 단지가 바뀜) + 범위 카드 레일. (BandShelf · band-shelf-model)
- 시세·타이밍: 타일 4칸 + **지수 선 + 월 거래량 막대 한 그림**(훑기·키보드) + 시장 온도 흰 카드 + 거래량 사실 카드 + 알림 레일. 국면 띠·비교 지역은 판정/데이터가 없어 생략.
- 지역별 시장 온도: 주 선택 칩 + 권역 + 타일 5칸 + **온도 타일 지도**(69곳, 5구간 토큰 색, 목록 보기 토글) + 1위 지역 12주 선 + 순위 레일. (TempMapClient · temp-map-model)
- 전세가율·갭 스크리너: 왼쪽 조건 패널(전세가율·갭·지역·예산, URL 쿼리는 replaceState 로만) + 타일 4칸 + 결과 표(막대·갭 강조·정렬 3종·단지 보기). (GapScreener · screener-model)
- lib/market/week-label.ts 분리(temperature.ts 는 server-only 라 클라이언트가 못 읽음).
