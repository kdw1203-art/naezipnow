# 1160 — 사용법을 풀어 쓴 문구 걷기

소유자 2026-11-12 "이런 문구는 AI스러운 문구 — 다른 페이지 포함 지워줘"(시안의 "적는 대로 채워짐" · "체크에서 자동으로" · "단지를 고르면 …가 채워짐" · "누르기만").

## 바뀐 것 — "~하면 자동으로 ~돼요" 식 설명을 사실 한 줄로(또는 삭제) · 17곳
- 임장노트 쓰기 레일: "현장 체크(2단계)를 표시하면 5축 점수가 채워짐 ›" → "현장 체크 ›"
- 임장노트: AI 초안 로그인 안내 · AI 정리 대기 카드 · 카드 만들기 · 회차 비교 · 노트 진열 안내
- 마이: 미션 · 친구 초대 · 저장한 검색(설명 줄 삭제) · 단지 내 기록 탭
- 분석: 내 기준 순위 · 시나리오 · 지도에서 고르기
- 정비사업 화면 · 주간 아카이브 · 초대 화면 · 지역 위젯
- 시안에만 있던 문구(적는 대로 채워짐 등)는 실제 화면에 넣지 않았다.

## 손대지 않은 것
- 결제 · 약관 · 개인정보 고지(사실을 알려야 하는 문장) · 오프라인 저장 안내 · 채팅방 나가기 확인.
- 1159 포함(임장노트 쓰기 한 화면).
