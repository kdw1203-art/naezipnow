# 1145 — 지역 화면 홍보 칸 · 임장노트 검색 · 관리자 DB 용량

- 지역 화면(/region/[id]) 오른쪽 레일에 전문가 홍보 한 칸(그 지역 활동 · 무료 100일 또는 프로 구독 중 · "홍보" 표시).
- 게시판(/board)에 "임장노트" 추가 — 공개 노트를 제목 · 단지명 / 요약 / 지역으로 검색, 20개씩 쪽 번호.
- 관리자 서비스 상태 "사이트" 칸에 DB 용량 줄 — 전체 크기 · Pro 포함 용량(8GB) 대비 % · 가장 큰 표. sql 214(admin_db_stats 함수 · service_role 전용).
  실측 2026-11-11: 400MB(실거래 245MB · 13개월 치) · 조직 요금제 pro.
- 제안 목록 중 "지역 거래량 막대"(지역 화면 시세 흐름 카드의 거래량 탭) · "최근 오류 보기"(운영 콘솔)는 이미 있는 기능이라 새로 만들지 않았다. 거래량 탭은 sql 212 실행 뒤 값이 나온다.

확인: 빌드 통과 · 단위 테스트 2,641.

## 1146 추가
- 전문가 홍보를 목록 "사이"로: 동네 글은 광고 칸과 같은 순번에, 임장노트는 공개 목록의 세 번째 글 뒤에 한 칸(내 노트 보기에는 없음).
- 새 DB 작업은 2026-11-11 에 직접 반영했다(sql 211 · 212 · 213 · 214) — 지역 월 집계 676행 생성, 매일 갱신 잡 등록, 기본 정보 · 전문가 홍보 열, DB 용량 함수. 관리자 권한도 부여.
