# 1001 — 토스페이먼츠 "홈페이지 변경(nuguzip.com → naezipnow.com)" 반려 분석과 보완

반려 통지(2026-09-12, 상점관리자·알림톡): **"변경 원하시는 홈페이지 내 결제수단 신용/체크카드가 확인되지 않습니다.
결제창 연동 가능 여부 확인 부탁드립니다. 확인 후 재신청 부탁드려요."** — MID `nuguzibowg`(계약완료), 등록 홈페이지 `https://nuguzip.com`.

## 1. 토스 심사가 보는 것 (공식 기준)

토스페이먼츠 블로그 「전자결제 심사, 한 번에 통과하는 방법」과 PG 연동 헬프 문서(심사 미비 사항)를 대조한 체크리스트.

헬프 문서(식스샵 토스 심사 미비 사항)는 "**결제창 연동 미확인** → 비회원 구매를 '사용'으로", "**도메인 변경** → 재심사 요청에
변경된 도메인과 내용 기재"를 해법으로 적고 있다. 즉 반려 사유는 우리 사이트에 결제수단 표기가 없어서가 아니라,
**심사자가 계정 없이 카드 결제창까지 도달하지 못해서**다.

## 2. 왜 심사자가 결제창을 못 봤나 (코드 실측)

- 운영 일반 결제 클라이언트 키는 **결제창형(`live_ck_…`)**, 빌링 키는 위젯형(`live_gck_…`)이다(운영 번들 실측).
- 결제창형 키는 `payment().requestPayment` 에 **주문번호가 필수**인데, 주문(`POST /api/payments/toss/create`)은 **로그인한
  사람만** 만들 수 있었다(401). 그래서 비로그인 방문자는 `/subscription/checkout` 에서 "카드 결제창은 로그인해서 주문이
  만들어진 뒤 열려요" + "로그인하고 결제하기"까지만 봤다 — 결제창은 한 번도 뜨지 않는다.
- 990 이 만든 "비로그인 미리보기"는 **위젯형(gck) 키를 전제**로 결제수단 목록(iframe)을 그리는 것이었다. 운영 키가 ck 라
  그 미리보기조차 빈칸이었고, 심사자에게 보인 것은 글로 적힌 "신용카드 · 체크카드" 한 줄뿐이었다.

## 3. 보완 (1001)

1. **비회원(게스트) 단건 결제** — 플러스 주간권(7일 · 1,100원)만.
   - `/subscription/checkout?tier=pro&billing=weekly` 에서 비로그인이면 **이메일 입력 → 주문 생성 → 토스 카드 결제창**(ck:
     `payment().requestPayment({method:"CARD"})`, gck: 위젯 `requestPayment`)이 바로 열린다. 로그인은 둘째 길.
   - 서버 `POST /api/payments/toss/create`: 세션이 없고 `billing=weekly` 이며 `guestEmail` 이 유효하면 주문을 만든다
     (`metadata.guest=true, claimPending=true`). 정기·리포트 결제는 그대로 로그인 전용. 속도 제한·고지 게이트 동일.
   - 승인(`confirmTossOrder`): 게스트 주문은 소유자 대조를 생략(결제창을 연 사람만 `paymentKey` 를 갖는다)하되,
     이용권은 **결제자가 그 이메일 계정으로 로그인해 있을 때만** 즉시 켠다. 그 밖에는 `claimPending` 으로 남기고
     **영수증 메일**에 "이 이메일로 가입/로그인하면 자동 연결"(가입 링크 포함)을 싣는다 — 이메일만 적으면 남의 계정에
     붙는 셈이라, 1,100원으로 상위 플랜 사용자를 7일 주간권으로 강등시키거나 환불로 이용권을 끊을 수 있다.
   - 연결(`lib/payments/guest-claim.ts`): 로그인·가입(`ensureAppUserRow`) · `/payment/success`(본인 복귀) · `/my` ·
     `/my/subscription` 에서 대기 중인 게스트 결제를 선점 UPDATE 로 한 번만 적용한다.
   - `/payment/success` 는 `orderId` 만으로는 **본인 주문일 때만** 결과를 보여 준다(주문번호는 비밀이 아니다).
   - 웹훅(DONE)도 같은 `applyPlanForPayment` 경로 — 지연 승인도 동일하게 처리.
2. 정기(월간·연간) 비로그인 화면에 "계정 없이 결제하려면 → 플러스 주간권" 링크 — 심사자가 가장 큰 버튼(플러스 시작하기)을
   눌렀을 때도 카드 결제창까지 한 번의 클릭으로 닿는다.

## 4. 재신청 절차 (소유자 — 상점관리자에서 직접)

1. 1001 배포가 끝난 뒤 시크릿 창에서 확인: `https://naezipnow.com/subscription` → "주간권 구매" → 이메일 입력 →
   "1,100원 카드로 결제하기" → **토스 카드 결제창**이 뜨는지(결제는 취소해도 됨).
2. 토스 상점관리자 → 내 상점 → **MID 정보 → 기본 정보 "변경"** → 홈페이지 주소 `https://naezipnow.com` 으로 재신청.
3. 신청 메모(요청사항)에 아래를 그대로 붙인다.

```
홈페이지 주소 변경 재신청: https://nuguzip.com → https://naezipnow.com (도메인 이전, 동일 서비스·동일 사업자).
nuguzip.com 은 naezipnow.com 으로 301 리다이렉트됩니다.

결제창 연동 확인 경로(회원가입 없이 가능):
1) https://naezipnow.com/subscription 에서 "주간권 구매" 클릭
2) https://naezipnow.com/subscription/checkout?tier=pro&billing=weekly 에서 이메일 입력 후
   "1,100원 카드로 결제하기" → 토스페이먼츠 신용/체크카드 결제창이 열립니다.
결제수단 안내: https://naezipnow.com/subscription/payment-methods
정기결제(월간·연간, 빌링키)는 회원 전용이며, 확인이 필요하시면 아래 테스트 계정으로 로그인 후
https://naezipnow.com/subscription/billing?tier=pro&billing=monthly 에서 카드 등록창을 확인하실 수 있습니다.
테스트 계정: (아이디)          (비밀번호)
사업자 정보·이용약관·개인정보처리방침·환불규정은 모든 페이지 푸터 및 https://naezipnow.com/legal/terms#refund 에 있습니다.
```
   테스트 계정 아이디·비밀번호는 소유자가 직접 채운다(채팅·코드에 적지 않는다).
4. 심사 결과는 알림톡으로 온다(평균 영업일 기준 수일). 다시 반려되면 반려 문구를 그대로 전달해 달라.
