## 바뀐 것

- 정비구역 위치 붙이기를 서울 → 전국으로. 위치는 지어내지 않는다:
  - 구역 이름에 지번이 적힌 것(번지 · 세 자리 이상 · 부번) → 지오코딩
  - 같은 시군구에 같은 이름 단지가 하나뿐인 것 → 그 단지 좌표 (운영 자료로 세어 본 값: 서울 밖 15곳)
  - 부산: 부산광역시 정비사업 정보(공공데이터포털 3069406)의 "위치"(대표 지번) → 지오코딩. 답이 그 구가 아니면 버린다
- 서울 밖 구역의 시군구는 "부산 동구"처럼 시도 약칭을 붙인다(같은 이름 구가 여러 시에 있다).
- 정비사업 지도 탭(지도 · 내용): 누른 표시는 바로, 본문 바꿔 그리기는 뒤로(운영 INP 경고 382ms).

## 확인하지 못한 것

- 부산 자료는 실호출을 해 보지 못했다(이 작업 환경에서 키를 쓰지 않는다). 응답 꼴이 달라도 읽도록 느슨하게 짰고, 못 읽으면 0건으로 넘어간다. 적재 기록의 "부산 자료 N"으로 확인.
- "촉진1 · 연산7" 같은 번호식 이름(서울 · 부산 밖 대부분)은 공개 자료에 위치가 없어 이번에도 지도에 못 오른다.
