## 1. 지시별로 한 것

### 지시 1 · 8 — 데스크톱과 모바일을 다르게, 데스크톱 밀도

- 모바일: 1012 의 75% 배율·간격 60%·한 줄 규칙 유지. 캡션 글자 11 → 12px(배율 뒤 화면 9px 는 너무 작았다),
  빈 상태 그림 64px, 홈 히어로 부제 숨김, 광고는 첫 목록 바로 아래 한 번(`lg:hidden`).
- 데스크톱: `app/globals.css` md+ 블록 — 간격 단위 4 → 3.5px(Tailwind 숫자 유틸 11,000여 곳이 한 번에 0.875 배),
  카드 패딩 18 → 16, 히어로 22 → 20, 글자 크기는 그대로, 40px 조작 하한 고정. 검토한 자료와 옮긴 규칙은
  `docs/layout-principles-1015.md`(NN/g F 패턴 2006/2017 · Hoober 손잡이 2013 · Baymard 줄 길이 · WCAG 1.4.8).
- "빈공간 확보": 넓은 화면은 본문을 늘리지 않고 오른쪽 레일(`lg:grid-cols-[minmax(0,1fr)_340px]`)에 요약·관련 글·광고를
  세운다 — 단지 상세·임장노트 상세·뉴스룸·동네 서브(청약·공급·경매·정비)·분석 도구·요금제·내 정보·여정·리포트·실거래·가이드.

### 지시 2 — AI 가 쓴 티

- 부제·설명형 문장을 사실 한 줄로(홈 AI 정리 "현장 메모 저장 → 장단점 · 리스크 · 확인 항목으로 정리. 로그인은 저장할 때만.").
  노트 쓰기 단계 제목 "위치와 방문 정보 / 현장 체크 / 메모와 판단". 분석 도구 머리에서 페르소나 배지·전제문 제거.
  "다음 행동" 등 라벨 단순화. 임베드 안내 문구.
- 게이트 `scripts/check-ai-look.mjs` 허용 목록 래칫: 7 파일 제거(hub-record-start · analysis/page · AuctionsClient ·
  ComplexReviews · not-found · notes/[id]/page · safety), 3 파일 축소(DevDealsListClient 2 · MyHubView 3 · NoteForm 2),
  문구 허용에서 developers 제거.

### 지시 3 — 안내 블록은 ⓘ 로

- 홈: 예산 칩(`HomeBudgetChips`)·시작 문 넷(`HomeStartDoors`) 삭제 → "처음이라면 ⓘ" 한 줄(`Explain`, 네 항목 + 예산은 지도 필터 안내).
- 동네 피드: 정렬 기준·Lab 설명 → ⓘ. 임장 점수 설명 → ⓘ. `Explain` 은 데스크톱에서 마우스를 올리면 미리보기
  (`.explain-wrap/.explain-tip`, hover 가능 기기만), 모바일은 탭.

### 지시 4 — 색·부연 라벨

- 홈·동네 홈 뉴스 칸: 한지/파랑 색판 → 흰 카드 + 행 선만(`data-tone="plain"` 신설). 광고 배너 카드 평면화.
- "사람의 기록" · "이야기" 칩 · "자동 수집 최신" · "Lab 데이터 카드" · "지금 이 피드에 실린 글 기준" · "뉴스룸 · 자동 수집" 제거.

### 지시 5 — 썸네일은 임장노트만, 비율

- 표지 렌더에 `shape=wide`(1200×630) 추가(`lib/notes/cover/*`, `/api/og/note-cover/[id]?shape=wide`). 피드 카드는
  `aspect-ratio: 1200/630` 칸에 wide 판 — 정사각을 넓은 칸에 억지로 채우던 잘림 해결. 목록 행은 44px 정사각.
- `PublicNoteCard` · 홈 노트 · 통합 검색 · 지도 단지 노트 · 관련 노트 · 단지 노트 요약에 `cover` 필드.
- 뉴스는 원본 사진(`newsImageUrl`)만. 사진 없으면 신문 아이콘 — 매체 이름 글자 칸(1013 방식) 폐기. 뉴스룸·주제 허브·홈·동네 홈 모두.

### 지시 6 — 뉴스룸, 네이버 뉴스 응용

`app/town/news/page.tsx`: 흰 머리(제목 "부동산 뉴스" + 날짜 줄 오늘/최근/접은 행, 버튼 동네이야기·주간 다이제스트) ·

### 지시 7 — 경쟁 사이트에서 가져온 것 (틀 안에서)

담당 5인이 영역별로: 단지 상세에 요약 행(`SummaryRow`, 호갱노노 식 핵심 수치 한 줄) 복귀 · 데이터 출처는 페이지 끝 접이식

요금제·내 정보 밀도 · 여정·리포트·실거래·가이드 리퀴드 톤 지정(`data-tone`) · 10px 캡션 → `t-caption`.
