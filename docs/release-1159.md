# 1159 — 임장노트 쓰기 한 화면(PC)

소유자 2026-11-12 "입력값 · 중간 과정 · 결과값을 한번에 다 볼 수 있는 페이지".

## 바뀐 것
- 임장노트 쓰기(`/notes/new` · 수정 화면): 넓은 화면(PC)에서는 위치 › 체크 › 기록 3단계를 넘기지 않고 한 화면에 펼친다. 왼쪽에 적고, 오른쪽 레일에서 미리보기 · 완성도 · 5축 점수 · 저장을 본다.
  - 단계 단추(1 위치 · 2 체크 · 3 기록)는 그 칸으로 내려가는 바로 가기. 이전 · 다음 단추는 없앴다(저장은 레일의 단추 하나).
  - 레일 5축 점수 아래에 "강점 · 약점 · 확인 남음"을 축 이름으로 적는다(점수에서 그대로 읽음).
  - 폰은 예전처럼 한 단계씩 — 체크 항목이 많아 한 줄로 늘이면 끝이 안 보인다.
- 1158 포함(정비사업 화면 색 기준 · 범례).

## 하지 않은 것
- AI 분석 화면: 살펴보니 단지를 고른 뒤에는 이미 한 화면(왼쪽 결과 · 오른쪽 내 조건과 다음 행동)이다. 시안처럼 도구 3개를 한 화면에 합치면 분석 1회가 3회분 호출이 되어 무료 한도(누적 3회) · 요금제와 부딪힌다 — 소유자 결정이 필요해 손대지 않았다.
- 페이지 통폐합: 방문 수 확인 전이라 손대지 않았다.

## 확인
- 단위 시험 2,658 통과 · 전체 빌드 통과 · 로컬 화면 캡처(PC · 폰).
