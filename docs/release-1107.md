# 1107 — 단지 화면 · 소개 간결화(글자 수 · 표 · 같은 사실 한 번)

소유자 2026-11-05 캡처 다섯 장(소개 · 푸터 · 단지 다요인 분석 · 단지 요약 · 입주물량) "글씨크기 글자수 디자인 표 등 전체적인 개선과 통합 간결화".
1106 위에 얹는다. DB 변경 없음 · 가격 · 결제 · 심사 화면(푸터 포함) 변경 없음 · 사실 · 수치 삭제 없음(자리만 옮기거나 한 번만).

## 단지 화면
- 다요인 분석(단지 · 임장노트 · AI 분석 결과가 같이 쓰는 판): 요인 하나가 세 줄(이름 · 막대 / 사실 / 출처)이라 8요인이 24줄이었다.
  → 넓은 판은 요인 한 줄 표(이름 · 사실 · 막대 · 판정), 폰은 두 줄. 풀이 · 출처 · 기준 시점 · 계산식은 판 아래 "근거 · 출처" 접힘 하나.
  "매수·매도 권유 아님 · 계산 방법"은 그대로 보인다.
- 요약 탭: 사실 열 조각을 이은 세 줄 문단 → 숫자 네 칸(최근 실거래가 · 비교 · 12개월 매매 · 전세 중앙). 준공 · 세대 · 전세가율은 위 개요 칸과
  전세가율 카드가 이미 말해 칸에서 뺐다(같은 사실 두 곳). 고지(공공데이터 기준 · 투자 권유 아님 · 현장 확인 후 판단)는 한 줄로.
- 요약 탭의 "내 기록 · 임장노트 회차별 모음 · 내 기록 열기" 카드 제거 — 바로 위 탭 줄의 "내 기록"과 같은 입구였다.
- 인근 입주물량: 목록 → 표(단지 · 위치 · 입주 · 세대). 위치는 동 하나(주소 전체 · 번지 · 사업명 괄호는 머리 지역과 겹치는 반복).
- 전월세 각주: 주의 네 가지 → 출처 · 가장 큰 주의 하나(나머지 셋은 제목 옆 ⓘ 풀이에 이미 있다).

## 소개
- 숫자 두 칸의 같은 꼬리("· 국토부 신고 기준" 두 번) → 카드 하나 · 기준 한 번.
- 운영 원칙: 칩 14개 · 펼침 표시 4개 · 두 줄로 접히는 제목 → 사이트 공용 사실 표(항목 | 사실) 한 장 · 제목은 짧게
  (사실 우선 · 없으면 없음 · 계산 공개 · 판단은 사용자). 문단에만 있던 사실 둘(읽은 데이터를 답과 함께 · 방식이 바뀌면 문서 갱신)은 낱말로 옮겼다.
- 아래 링크 칩 넷(방법론 · 용어사전 · 월간 리포트 · 고객센터)은 바로 밑 푸터와 같은 링크라 걷고 근거 문서(데이터 방법론) 하나만 제목 줄에.
