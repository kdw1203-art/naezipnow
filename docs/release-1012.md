# 1012 — "AI가 만든 사이트" 티 걷기 · 한 화면 한 가지 · 폰 배율 · 임장노트 썸네일

주인님 지시 흐름(원문 요지):

1. "AI로 만든 사이트 같아 보이는 부분 수정 · 색·글꼴·여백 규칙을 디자인 시스템으로 · 호갱노노·당근 부동산·네이버 부동산·숨고
   기준으로 점수를 매기고 넘을 때까지 · 상업 라이선스 확인 · 문구에 누가·언제·어디서 · 반짝이 배지·그라데이션 줄이기 · 자체 이미지 ·
   뉴스·임장노트 등 모든 곳에" → **v3 형태·문구 규율**
2. "모바일 글씨·디자인이 좀 크다, 약간 축소 + 비율 최적화 · 전체 페이지" · "임장노트는 인스타그램 참조"(목록 · 기본 3열 격자)
3. "너무 복잡하고 뭐가 중요한지 모르겠다, 필요 없는 말이 많고 분산돼 어수선하다 — 대폭 개편" → 방향 **한 화면 한 가지**,
   시안 3개(단지·동네·AI 분석) → "응 다 진행해줘" → **v4 전 페이지**
4. "상단 요약 · 글자는 요약본 · 문장 정렬 · 삐뚤한 교차 배치 싫다" → 한 줄 규칙 · 매소너리 제거
5. "첫 화면은 지금의 60~70%, 하단 메뉴는 80~90%" → 시안(지금·80·70·60) 보고 **60% / 메뉴 85%**
   → 이어서 "글씨는 75% 수준, 최대한 한 줄" → **글자 75% · 여백 60% · 메뉴 85%**
6. "임장노트를 쓰면 AI가 썸네일 3개를 만들어 고르게, 지금 있는 것들은 네가 만들어 적용" → 방식 **브랜드 템플릿 + AI 문구**
7. "목록들에 디자인적으로 구분·컬러감, 리퀴드 디자인 참고 — 특히 여정·리포트·요금제·청약·공매·실거래·임장 가이드" → **v4.1 리퀴드 목록**(톤 4종 유리판, 194곳 톤 배정)

## 1. 디자인 시스템 (docs/design-system.md 맨 위)

- **v4 — 한 화면 한 가지**(규칙 12 + 부품 표): 제목 한 줄 + 사실 한 줄 → 주인공 1개(숫자·검색·목록) → 1px 구분선 목록 행 →
  맨 끝 출처 한 줄/`<details>`. 네이비 히어로·워터마크·아이콘 타일·설명 배지·기능 설명 문장·같은 사실 반복·자사 안내 카드 제거.
  채움 파랑 버튼 화면당 1개. 모든 글 왼쪽 정렬. 매소너리 금지. 데스크톱은 가운데 760px 한 줄(지도·정비사업 지도 등 예외).
- **v3 — 형태·문구 규율**: 기준 사이트 4곳 실측표, "AI 신호" 표, 규칙 10, 채점표(A 정보 우선 · B 문구 구체성 · C 형태 규율, 통과선 8).
- **폰 배율**(3-1절): 화면 짧은 변 < 600px 인 폰만 뷰포트 배율 0.75(글자·아이콘·지도 모두 75%), 간격 단위 3px(여백 60%),
  탭바 85%. 두세 줄 말줄임 → 한 줄, h2~h4·목록 보조 줄 한 줄. 태블릿·데스크톱은 그대로.
- 라이선스: `docs/licenses.md` — Pretendard·Noto Serif KR(OFL 1.1), 선 아이콘(Lucide 파생, ISC), 직접 그린 일러스트(자체 저작),
  썸네일(자체 템플릿 + 자체 폰트 · 이미지 생성 모델 없음).

## 3. 임장노트 썸네일

- 흐름: 노트 저장 → `/notes/[id]/cover` 후보 3장(AI 문구 → 숫자 검증 → 모자라면 규칙 문구) → 고르면 `metadata.cover` 저장 → 목록·격자·동네 피드·프로필·공유 카드.
- 숫자 검증: 문구의 숫자는 전부 노트 원문 값이어야 한다(목록에 걸 때 다시 검증). AI 문구엔 "AI가 노트에서 뽑은 문구" 표시.
- **운영 DB 변경(2026-09-27, 통합자)**: 공개 노트 33편의 `inspection_notes.metadata.cover` 를 채웠다. 문구는 통합자가 각 노트 원문을 읽고
  골랐고 33편 모두 숫자 검증 통과. 스키마 변경 없음(기존 jsonb). 배포 전 코드는 이 키를 읽지 않으므로 지금 화면에는 영향이 없다.
  되돌리기: `update public.inspection_notes set metadata = metadata - 'cover' where metadata ? 'cover';`
- AI 정리 저장 경합 수정: `app/api/inspection/ai/route.ts` 가 저장 직전 최신 metadata 를 다시 읽는다(고른 썸네일이 지워지지 않게).

## 6. 주인님 확인이 필요한 것

- **요금제·결제 화면**은 토스 심사 때 제출한 화면이다. 가격·상품명·문구 사실은 그대로이고 배치·문장 모양만 바뀌었다
  (`check-toss-review-freeze` 통과). 배포 뒤 한 번 훑어봐 주세요.
- 폰 글자는 75%(본문 13px → 폰에서 약 10px), 버튼 높이 40px → 폰에서 약 30px. 더 크게/작게는 `app/layout.tsx` `MOBILE_SCALE` 한 값.
- 하우스 광고(자사 안내 카드)를 주요 화면에서 뺐다(v4 규칙 9). 노트 상세의 article_end 광고 자리도 빠졌다 — 애드센스를 다시 켤지는 결정 필요.
