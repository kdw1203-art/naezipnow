# 1154 — 정비구역 지도 보강 · 전국 목록 걸러 보기

## 바뀐 것
- 주거환경개선을 지도 분류에 추가(공공주도 묶음) — 서울 36곳이 분류가 없어 지도에서 빠져 있었다.
- 조서에 지번이 없는 아파트 이름 재건축 구역은 **같은 자치구 · 같은 이름 단지가 하나일 때만** 그 단지 좌표로 찍는다(요약에 "같은 이름 단지 기준"). 단지 좌표가 쌓일수록 늘어난다.
- `/redev-list`: 추진 단계 걸러 보기 · 세대수 많은 순 · 지도에 찍힌 구역은 이름에서 상세(지도)로 바로 간다.
- 1153 포함: 좌우 광고 띠 고정 크기 칸 · 관리자 API 2단계 인증 · 관리자 실행 판 정비구역 작업.

## 확인
- 단위 시험 전부 통과 · 전체 빌드 통과.
- 지도 반영 수는 운영에서 "정비구역 지도 위치" 작업을 돌린 뒤 나온다(2026-11-11 현재 아직 0곳 — 한 번도 돌지 않음).
