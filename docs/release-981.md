# 981 — 도구마다 다른 것을 묻는다 + 지역·시장 4종에도 성격 (2026-09-09)

980 이 **색·연출·말투**를 도구마다 갈랐다면, 981 은 소유자가 고른 범위 중 남아
있던 두 가지를 채운다 — **입력**과 **지역·시장 4종**.

---

## 1. 가장 큰 것: 기능이 없던 게 아니라 물어보지 않고 있었다

워크벤치는 12종 전부에게 같은 것만 물었다 — 가용 예산 하나, AI 서술 체크박스 하나.
그런데 `lib/ai/analysis-engine.ts` 를 읽어 보면 **엔진은 도구마다 다른 입력을 이미
읽고 있었다.**

| 도구 | 엔진이 읽는 입력 | 화면이 물었나 |
|---|---|---|
| 매수 타이밍 | `horizonMonths` · `urgency` · `entryStrategy` · `watchList` | ✗ |
| 임장 동선 | `goal` · `mustHaves` · `maxTravelMinutes` · `preferredInspectionDays` | ✗ |
| 수익률 계산 | `ltvPct` · `mortgageRatePct` · `loanTermYears` · `holdingYears` · `targetYieldPct` | ✗ |
| **갭투자 진단** | **`maeMan` · `jeonMan`** | ✗ |
| 계약 리스크 | `jeonseMan` · `marketRatioPct` · `hasRegistrationCheck` · `hasInsurance` | ✗ |
| 투자 체크리스트 | `propertyName` · `checklistFocus` | ✗ |
| 종합 진단·시세 예측 | `currentPriceMan` · `areaPyeong` · `regionFreeText` | ✗ |

굵게 적은 갭투자가 가장 뚜렷하다. 엔진은 `maeMan - jeonMan` 으로 갭을 계산하는데
화면이 두 값을 묻지 않았으니 **갭이 늘 0** 이었다. 도구 이름이 갭투자 진단인데.

### 규칙 하나만 지켰다 — 엔진이 읽지 않는 입력은 만들지 않는다

결과에 영향이 없는 입력칸은 화면을 풍성해 보이게 만들 뿐 사용자를 속인다.
그래서 단위테스트가 **`analysis-engine.ts` 소스를 실제로 읽어** 화면이 올린 키가
엔진에 존재하는지 대조한다. 눈으로 맞춘 목록은 반드시 어긋난다.

```
test("화면이 묻는 입력은 전부 엔진이 실제로 읽는 필드다 — 결과에 영향 없는 칸 금지")
  → ENGINE.includes(`in_.${f.key}`)
```

### 함정 두 개를 코드로 막았다

- **비운 칸은 키 자체를 안 보낸다.** 빈 문자열을 보내면 엔진의 `Number(in_.x ?? 0)`
  이 0 으로 읽어 "0 만원을 입력했다"가 된다.
- **단위가 섞여도 숫자를 뽑되, 숫자가 하나도 없으면 안 보낸다.** `"4.2%"` → `4.2`,
  `"예순"` → 안 보냄. (`Number("")` 이 0 이라 같은 함정에 다시 빠진다.)
- 토글은 **끈 상태도 보낸다** — 계약 도구에서 "등기부등본 미확인"이 곧 경고 조건이다.

## 2. 지역·시장 4종에도 성격

980 에서는 허브 카드까지만 바뀌었다. 이제 페이지 안쪽도 바뀐다.

| 화면 | 성격 | 하는 일 |
|---|---|---|
| 면적대별 실거래 시세 | 실측 | 면적대별로 실제 체결된 값을 늘어놓습니다 — 호가가 아닙니다 |
| 시세·타이밍 분석 | 흐름 | 12개월 지수와 모멘텀으로 지역이 어느 쪽으로 가는지 봅니다 |
| 지역별 시장 온도 | 체온 | 매주 잰 기록을 이어 붙여 지금이 아니라 추세를 보여 줍니다 |
| 전세가율·갭 스크리너 | 순위 | 시군구를 전세가율로 줄 세우고 실측 갭을 먼저 보여 줍니다 |

`PageShell` 에 `toolScope` 를 받게 해서 `<main>` 한 곳에 도구 색을 꽂는다 —
페이지마다 색을 적지 않는다.

**네이비 위에서는 액센트를 글자에 쓰지 않는다.** 도구 액센트는 흰 바탕/다크 표면
기준으로 대비를 맞춘 값이라(980 단위테스트) 네이비 히어로 본문에 그대로 쓰면
대비가 무너진다. 밝은 칩 안쪽에서만 쓰고, 네이비 위 글자는 on-dark 토큰 그대로.
