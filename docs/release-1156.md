# 1156 — 관리자 API 2단계 인증 마무리 · 정비구역 목록 내려받기 · 단지 좌표 속도

## 바뀐 것
- 관리자 API 2단계 인증: 제 손으로 관리자 확인을 하던 14개 경로(회원 · 결제성 화면 · 신고 · 배너 · 문자 등)에도 같은 확인을 붙였다. 등록 계정은 확인 표식이 있어야 통과, 등록 전 계정은 예전 그대로.
- `/redev-list` 엑셀로 내려받기(CSV) — 화면과 같은 조건 · 2,000행까지 · 마지막 줄에 출처.
- 단지 좌표 채우기: 한 번에 200곳 → 800곳(하루 4회 · 4분 예산은 그대로). 2026-11-11 현재 15,052곳 중 520곳만 좌표가 있다.
- 1154 · 1155 포함(주거환경개선 지도 분류 · 같은 이름 단지 좌표 · 목록 걸러 보기 · 지적도 함께 보기).

## 확인
- 단위 시험 전부 통과 · 전체 빌드 통과.
- 이미 있어 손대지 않은 것: 구역 상세의 결정 고시 이력 · 주변 단지 실거래 · 가까운 구역 · 정비구역 사이트맵.
