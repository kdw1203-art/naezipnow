## ① 광고 — 버그(문서 · 주석의 의도와 반대로 동작)
- 의도: 비로그인 방문자 = 광고 있음 · 프로 이상 플랜 = 광고 없음 · 결제 · 마이 · 구독 · 로그인 등 제외 경로 = 광고 없음(docs/adsense-readiness.md · AdSenseLoader 머리 주석 · AdFreeGate [1098] · lib/ads/viewer).
- 실제: Auth.js 가 비로그인에게 돌려주는 null 세션을 광고 판정 세 곳(AdSenseLoader · AdZoneUnit · AdSenseUnit)이 "조회 실패 → 광고 안 함"으로 읽었다.
  2026-08-04(최적화 #26)부터 비로그인 방문자에게 광고 요청이 한 번도 나가지 않았다(pauseAdRequests 늘 1 · 광고 칸 0 · 하우스 배너만). 같은 화면의 AdFreeGate 는 "광고 있음"이라 판정이 서로 달랐다.
- 고침: 판정 한 곳(lib/ads/ad-free adSenseAdFree) — null + 로그인 흔적 쿠키 없음 = 비로그인 = 광고 · null + 흔적 있음 = 조회 실패 = 광고 안 함 · 그 외 플랜으로. 제외 경로에서는 판정을 비운다.
- 잠금이 풀리자 드러난 둘도 같이 고쳤다(로컬 빌드 실측):
  · 폰에서 CSS 로 숨긴 PC 전용 광고 칸의 <ins> 까지 채우려다 애드센스 "폭 0" 오류(TagError)가 페이지 오류로 났다 — push 는 문서 순서상 첫 빈 <ins> 를 채우므로, 칸이 보일 때만 <ins> 를 그린다.
  · CSP 가 애드센스 부정 트래픽 점검(*.adtrafficquality.google)과 www.google.com 프레임을 막았다 — Google 애드센스 CSP 안내 목록대로 허용.
- 검증(로컬 빌드 · 광고 요청은 막고 판정만): 비회원 pauseAdRequests 1 → 0 · TagError 0 · CSP 위반 0.

## ② 속도 3차

- 페이지 전환: class 토글 대신 body.animate(같은 곡선 · 시간) · 건너뛰기 링크 text-decoration 상속이 프레임마다 body 자식 87개 재계산 → 전환 한 번 스타일 92 → 12ms · 그리기 96 → 28ms.
- 테마: 인라인 스크립트가 이미 붙인 html class 를 next-themes 가 마운트 때 지웠다 다시 붙이던 것(다크 사용자 문서 전체 재계산) → 상태만 next-themes · class 는 바뀔 때만.
