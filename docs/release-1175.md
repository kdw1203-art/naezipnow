# 1175 — 사업장 주소 도로명까지만

소유자 2026-11-14 "사업장 주소를 도로명까지만" · 토스 · 카드사 심사는 끝났다고 확인.

## 바뀐 것
- 전 페이지 하단 주소: "경기도 안양시 동안구 관평로212번길 21"(동·호수 · 건물명 제외). 사업자 정보를 읽는 다른 곳(구조화 데이터 등)도 같은 값 하나를 쓴다.
- 심사 잠금 검사(check-toss-review-freeze)의 주소 값도 새 표기로 바꿨다.
- 코드 주석 · 예시 글(노트 공유 이미지 기본 제목 · 크리에이터 입력 예시)에 남아 있던 동 번호를 일반 예시로 바꿨다.
- 1174(단계 안내 한두 줄) 포함.

## 알아 둘 것
- 사업자등록증 · 통신판매업신고증의 주소는 그대로다. 토스 · 카드사가 다시 확인을 요청하면 전체 주소를 되돌려야 할 수 있다.
- 저장소의 예전 문서(docs/toss-*.md)와 커밋 기록에는 전체 주소가 남아 있다.
