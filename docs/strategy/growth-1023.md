## 1. 성장을 막는 병목 5 (사업 운영 전략가)

### B1. 제품 100% · 유통 0% 의 시간 배분
- **왜 위험한가**: 2주 9차 배포는 방문자 32명에게 보여 줬다. 기능이 하나 늘 때 가입이 늘지 않는다는 것이 9차 연속으로 실측됐다(가입 9월 1명). 제품 개선은 이제 성장의 원인이 아니라 결과를 기다리는 비용이다.
- **지표**: 주간 배포 수 대비 주간 신규 방문자·가입(브리핑 편입). 기준: 4주 연속 "배포 ≥3 · 가입 ≤2" 이면 배분이 틀린 것.
- **바로 할 행동**: **[실행]** 1023 을 마지막 "화면 차수"로 잠근다 — 다음 4주(1024~) 배포 대상은 유통·온보딩·콘텐츠 자동화만(3장 D 표). 화면 요청은 `docs/backlog-ui.md` 에 적어 두고 4주 뒤 재개.

### B2. 임장노트 작성자 1명 — 플라이휠에 두 번째 사람이 없다
- **왜 위험한가**: U3(기록이 쌓일수록 못 떠난다)는 작성자가 여럿일 때만 성립한다. 지금 38편은 전부 Lab(AI) 노트라 "이웃의 현장 기록"이라는 브랜드 약속이 사이트에 증거가 없다. 방문자가 보는 첫 화면이 그 증거다.
- **지표**: **노트 작성자 수(≠1)** · 이웃 노트 편수/주 · 노트 공유 링크 유입(utm_source=share, 지금 0).
- **바로 할 행동**: **[OWNER]** 첫 작성자 10명은 시스템이 아니라 사람이 데려온다 — 안양·과천·의왕 임장 카페·오픈채팅에서 "노트 1편 = 실거래 리포트 PDF 1부"로 직접 섭외(문안은 2장 R6). **[다음]** 노트 저장 직후 카카오 공유 카드(OG)를 저장 완료 화면의 첫 버튼으로.

### B3. 소유자 손에서 멈춘 자동화 — 소셜 42건 큐 · 결제 갱신 크론 실패 · 경보 수신자 없음
- **왜 위험한가**: 만들어 둔 회로가 "켜지지 않은 상태"로 41일이다. 매일 큐만 쌓이고 발행 0 — 콘텐츠 공장이 돌지만 출구가 잠겨 있다. 결제도 같은 구조(Vault `cron_secret` 미등록 → 갱신 실패, `docs/ops/owner-checklist.md` #2). Resend 키가 없으면 이 실패를 알리는 메일도 안 간다(#1).
- **지표**: `social_uploads` 큐 최고령 일수(지금 41일) · owner-checklist 체류 14일 초과 건수(지금 최소 10건, 9/2 기준 문서).
- **바로 할 행동**: **[OWNER · 30분]** `docs/social-shorts-setup.md` 절차로 IG 토큰 2개 · YT 3개 등록, Resend 키, Vault `cron_secret`. 30분 안에 못 하면 **큐 생성 크론(`/api/cron/social-autopost`)을 끈다** — 켜지지 않을 회로는 운영 소음이다. 둘 중 하나를 이번 주에 결정.

### B4. 유입 자체가 0에 가깝다 — 그리고 한국 검색의 80% 가 비어 있다
- **왜 위험한가**: 30일 랜딩 82건 중 Google 18, 네이버 4. 한국 부동산 탐색은 네이버 검색·카페·블로그에서 시작되는데 우리는 그 채널에 존재하지 않는다(네이버 서치어드바이저 등록 여부 **미확인**). 순방문자 32명이면 어떤 온보딩 개선도 통계가 안 나온다.
- **지표**: 주간 순방문자(목표 4주 뒤 300) · 네이버 랜딩 비율 · 사이트맵 색인 수(`seo_index_coverage` 는 아직 0행 — 측정부터).
- **바로 할 행동**: **[OWNER · 10분]** 네이버 서치어드바이저에 naezipnow.com 등록 + 사이트맵 제출. **[다음]** Lab 노트를 네이버 블로그 글 초안(제목·요약·링크·대표 이미지)으로 자동 내보내는 관리자 버튼 — 네이버는 발행 API 가 없으므로 붙여넣기 30초까지만 줄인다.

### B5. 배포가 소유자 손을 거친다(git 403) — 하루 단위 지연
- **왜 위험한가**: 세션이 push 를 못 해 매 차수를 zip + PowerShell 로 소유자가 적용한다. 지금은 하루 1회라 견디지만, 유통 실험은 "오전에 고치고 오후에 본다"가 생명이다. B1 을 실행하면 배포 대상이 작은 실험으로 바뀌므로 이 지연이 곧 병목이 된다.
- **지표**: 패키지 생성 → 프로덕션 READY 시간(1022: 약 반나절).
- **바로 할 행동**: **[OWNER · 5분]** GitHub 저장소에 세션용 배포 키(또는 `contents:write` 스코프 fine-grained PAT)를 발급해 Vercel 환경이 아닌 세션 프록시에 등록 — 값은 대화에 넣지 말고 절차만 통보. 그 순간부터 2장 R1 의 OWNER 단계가 사라진다.

**병목이 아닌 것(자원을 쓰지 않는다)**: 결제 매출 0 — 회원 1,000명 전에는 매출을 만들려는 시도 자체가 시간 낭비다(요금제 화면은 토스 심사 동결 그대로 둔다). 성능(LCP 1.4s) — 충분하다. 데이터 품질(`data_quality_snapshot` 이상치 0) — 충분하다.

## 3. 불공정 우위 — 남이 못 따라 하는 것만 (우위 전략가)

v1 의 U1~U5 는 방향이 맞았고 실행이 없었다. 6주 실측으로 걸러 **지금 실제로 우리만 가진 것 4개**로 줄이고, 각각에 제품 구조·콘텐츠·유통·브랜드를 붙인다. "좋은 UX" "친절한 온보딩" 같은 누구나 하는 조언은 뺐다.

### A. 원가 0 의 콘텐츠 공장 — 데이터 92만 건 × AI 세션
호갱노노·네이버는 데이터가 더 많지만 **글을 못 쓴다**(조회 UI 회사이고, 콘텐츠 팀은 광고 수익 구조상 단지 단위 글을 만들 이유가 없다). 당근·숨고는 부동산 데이터 자체가 없다. 우리는 실거래 923,577건·단지 40,028·청약 2,884·공매 7,516 을 매일 읽는 AI 세션이 있고, 뉴스 618건·Lab 노트 33편이 이미 그 증거다.
- **상품 구조**: 단지마다 "이 단지의 Lab 노트"가 존재하는 상태를 목표로 — 단, 얇은 대량 페이지는 소프트404 이므로 **실거래 20건 이상 단지만**, 안양·과천·의왕부터(R4 큐).
- **콘텐츠**: 매일 1편 Lab 노트 + 매주 1편 "이번 주 신고가/최저가 5건" 카드(소셜 큐가 이미 만든다 — 출구만 열면 된다, B3).
- **유통**: 네이버 블로그 초안 내보내기(B4) · 카카오 공유 카드 · 소셜 큐 42건.
- **브랜드**: "사람이 안 쓰고 데이터가 쓴다"가 아니라 **"숫자는 국토부 신고값 그대로, 해석만 AI"** — 이미 사이트 하단 면책이 이 문장을 잠그고 있다(`check-ai-compliance`).

### B. "가는 사람의 앱" — 기록 워크플로는 조회 앱이 구조적으로 못 만든다
호갱노노가 임장노트를 붙이면 조회 트래픽의 0.1% 가 쓰는 기능이 되어 우선순위에서 밀린다(리스팅 DNA). 우리는 작성 3단계 · 회차 묶기 · 같은 단지 다른 노트 · 회차 비교 · best 월 · 저장 전 요약(1023)까지 워크플로 전체가 있다. 문제는 사용자 증거(작성자 1명)다.
- **상품 구조**: 노트 저장 완료 화면 = 공유 카드가 첫 버튼(B2). 노트 3편이면 "내 임장 지도"(이미 지도의 내 노트 레이어가 있다 — 링크만).
- **콘텐츠**: Lab 노트를 "빈칸 있는 노트"로 — 데이터 칸은 채워져 있고 관찰 칸(소음·주차·결로)은 비어 있다. 방문자가 그 칸을 채우면 자기 노트가 된다(작성 마찰 최소).
- **유통**: 임장 크루(오프라인 소모임)의 표준 도구 — 크루장 5명에게 "크루 페이지 + 코스 기록"을 준다(모임 기능 있음, 시드 0).
- **브랜드**: "시세는 누구나 봅니다. 현장은 가 본 사람만 압니다." 유지.

### C. 안양·과천·의왕에서 "제일 잘 아는 곳" — 전국 얕게가 아니라 한 곳 깊게
소유자가 안양 관양동에 있다. 대기업은 특정 시군구에 사람을 붙이지 않는다. 1주일에 1편씩 현장 노트가 쌓이는 시군구는 6개월 뒤 검색·카페·크루 모두에서 "그 동네는 내집나우"가 된다. 이것은 돈으로 못 산다(시간 + 현장).
- **상품 구조**: 동네 홈(`/town/anyang-dongan` 등)이 랜딩 — 1023 에서 동네 홈 머리에 "공개 임장노트 N · 최근 3건"이 붙었다. 0편이면 캡션이 사라지므로 이 숫자를 채우는 것이 곧 전략이다.
- **콘텐츠**: 안양 동안구·만안구·과천·의왕 실거래 20건+ 단지 목록 → R4 큐 상위 50.
- **유통**: 해당 지역 카페 3곳·오픈채팅 3곳(R6). 광고 0원.
- **브랜드**: "안양 임장은 내집나우" — 한 문장을 4개 시군구에서만 쓴다.

### D. 실거래 게임 — 데이터 회사가 못 만드는 "공유되는 놀이"
1020 에서 A|VS|B 실거래가 게임을 만들었다. 문제를 실제 신고값으로 내는 게임은 데이터가 없는 당근·숨고는 못 만들고, 호갱노노·네이버는 브랜드상(정보 서비스) 안 만든다. 게임은 회원가입 없이 돌고 결과 카드가 공유된다 — **가입 전 유입 회로**로 유일하게 "재미"를 가진 자산이다.
- **상품 구조**: **[다음]** 결과 화면에 "오늘의 5문제" 공유 카드(점수·동네·링크) + 매일 문제 자동 갱신(데이터로 가능). 가입은 "내 기록 남기기"에서만.
- **유통**: 소셜 큐의 카드 형식 하나를 "오늘의 실거래 퀴즈"로.
- **브랜드**: 딱딱한 데이터 회사와 반대 자리.

### 하지 않는 것(재확인)
시세 조회 정면전 · 매물 유통 · 범용 커뮤니티 · 전국 동시 확장 · 유료 광고 · 범용 전문가 매칭(v1 §1 그대로). 추가로 **결제·요금제 개선, 전문가·모임·자료실·IR·B2B 화면 개선**은 회원 1,000명까지 손대지 않는다(행 수 0 인 표들이다).
