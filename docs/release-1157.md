# 1157 — 정비구역 마커 색(진행단계) · 위치 붙이기 자동 실행

## 바뀐 것
- `/map` 정비사업 레이어: 마커 색 기준을 고른다 — 사업종류(기본) · 진행단계(구역지정 회색 → 착공 빨강 → 준공 초록). 범례도 같이 바뀐다.
- 정비구역 위치 붙이기(`/api/cron/redev-zone-locate`): 주 1회 → 하루 2회(05:50 · 17:50 UTC). 2026-11-11 현재 한 번도 돌지 않아 지도에 새 구역이 0곳이다 — 배포 뒤 다음 실행부터 사람이 누르지 않아도 채워진다. 이미 찍힌 구역은 다시 묻지 않는다.
- 1156 포함(관리자 API 2단계 인증 마무리 · 목록 내려받기 · 단지 좌표 800곳씩).
