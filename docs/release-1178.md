# 1178 — 개선 B 묶음: 단지 상세(내 기록 변동 · 모임 일정)

소유자 2026-11-14 "응 진행해줘"(B 묶음 8~15 · 재검토 뒤 진행).

## 바뀐 것
- 단지 상세 › 내 기록: 첫 방문 뒤 실거래 변동 한 줄(예: "방문 뒤 새 실거래 2건 · 85㎡ 12억 → 12.6억(+5%)"). 노트가 있을 때만.
- 단지 상세 › 내 기록: 내 모임이 있으면 "이 단지로 모임 일정 만들기". 누르면 모임 일정 탭이 이 단지를 고른 채 만들기 창으로 열린다(일정 이름 "○○ 임장").
- 두 줄 모두 못 읽으면 그 줄만 없다(노트 목록은 그대로).
