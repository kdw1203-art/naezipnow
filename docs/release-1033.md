# 1033 — 임장노트 타입·세부 기록 보완 (2026-10-05)

기준: 1032(tree 93356b5f) 위에 얹는다(1029·1029b·1030·1031 위에서도 적용 — 누적). DB 변경 없음.

소유자 지시: "좀더 검토해서 추가하고 보완할 수 있는 부분에 대해 추가해줘" — 1032 를 다시 보고 빠진 것·새는 것·이어지지 않는 것을 채웠다.

## 빠져 있던 것
- **단지 id 없는 위치**(빌라·오피스텔·직접 입력·장소 검색)에는 타입 카드가 아예 없었다 → 위치가 정해지면 카드가 서고, 단지 자료·실거래 칩 대신 면적 직접 입력 + 동·층·향 + 평면도(app/notes/new/NoteUnitPick.tsx `complexId: string | null`).
- **퀵모드(현장 한 화면)** 에 지도·타입이 없었다 → 위치 카드 아래 같은 조각(NoteForm `renderUnitPick`).
- 실거래 **조회 실패**가 "실거래 타입 없음"으로 그려졌다 → 실패·없음·불러오는 중 셋을 가른다.
- 지도 첫 자리: 서울시청 고정 → 직전에 쓴 단지 좌표(carryOver) → 위치 권한을 **이미 준** 기기는 내 위치(권한 창은 띄우지 않는다 · 손으로 움직인 뒤엔 건드리지 않는다).

## 이어지지 않던 것
- **재방문**(?revisit= · 1단계 "지난 체크 불러오기")이 타입을 잇지 않았다 → RevisitPrefill.unit, 비어 있을 때만 채움 · 배너 "위치·타입·태그·체크 이어받음".
- **3단계 요약·레일 미리보기**에 타입이 없었다 → "타입" 줄(lib/notes/finish-summary `unit`) · 미리보기 카드 단지 아래 한 줄.
- **완성도**에 타입이 없었다 → `unitSet` 을 넘길 때만 "타입" 항목(8항목 · 기존 7항목 호출은 그대로).
- **목록 카드**(공개 노트·내 노트) 바닥줄 맨 앞에 "84㎡ · 12층 · 남향"(lib/notes/feed-note).
- **AI 정리** 입력에 타입·세부 기록이 없었다 → PromptInput.unit/fieldDetail · 내용 해시(content-hash)에 있을 때만 포함(없는 노트의 해시는 그대로 → 기존 분석을 묵은 것으로 만들지 않는다).
- **회차 비교**(revisit delta)에 세부 기록 변화 — "방문 시각 주차 만차→여유" · "지하철 도보 7분→9분"(양쪽에 같은 항목이 있을 때만 · 들은 말은 비교 안 함).
- 상세 캐러셀에 **평면도 표식**(사진 역할).

## 새는 것(신뢰 경계)
- 서버가 unit·fieldDetail·photoRoles 를 **폼과 같은 파서**로 거른다(`sanitizeUnitMeta` · POST/PATCH 공통 · 길이·선택지·역할). 폼은 비우면 **null** 로 보낸다 — PATCH 가 기존 metadata 위에 덮어쓰므로 키를 지워야 예전 값이 되살아나지 않는다.
