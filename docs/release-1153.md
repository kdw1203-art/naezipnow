# 1153 — 좌우 광고 띠 고정 크기 칸 · 관리자 API 2단계 인증

## 바뀐 것
- 좌우 광고 띠: 형식을 맡기지 않고 **고정 크기 칸**으로 요청한다(160×600). 좁은 칸에 "자세히 알아보기" 글자 목록형이 들어와 "부동산 …" 으로 잘리던 것(소유자 2026-11-11).
  여백이 넉넉한 화면(1900px 부터 · 넓은 본문은 2060px 부터)은 띠 · 칸을 300×600 으로 넓힌다. 본문과 겹치지 않음(1920 · 1700 실측).
- 관리자 API(`isAdminApiRequest` 를 쓰는 16개 경로): 2단계 인증을 등록한 계정은 확인 표식이 있어야 통과한다. 등록 전 계정은 예전 그대로.
- 관리자 › 데이터 실행 판에 "전국 정비구역 목록" · "정비구역 지도 위치" 추가.
- `/redev-list` 안내 문구를 지도 반영에 맞게 고침.

## 확인
- 단위 시험 2,651 통과 · 전체 빌드 통과.
