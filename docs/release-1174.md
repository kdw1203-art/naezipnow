# 1174 — 단계 안내를 한두 줄로

소유자 2026-11-12 "이런 거는 한 줄이나 두 줄로 끝내자"(전문가 등록 단계 카드 4장).

## 바뀐 것
- 새 조각 `StepStrip`: 번호 칩 + 단계 이름을 › 로 잇는 한 줄, 꼭 필요한 사실은 아래 한 줄. 폰에서 모자라면 칩 단위로 다음 줄로 넘어간다(글자가 잘리지 않는다).
- 전문가 등록: 카드 4장(설명 3줄씩) → "신청 › 서류 심사 › 승인 › 인증 마크 · 홍보 1년 무료" + "서류는 운영자만 확인 · 승인된 사람만 등록 · 결과는 알림으로".
- 크리에이터 입점: 카드 3장 → "임장노트 작성 › 비공개 노트를 유료 리포트로 등록 › 구매는 리포트 상세 직접 링크" + 자격 · 판매 대상 · 가격 범위 한 줄.
- 1173(광고 칸 크기 고정) 포함.

## 손대지 않은 곳
- 개발물건 수수료 안내(/dev-deals/fees)는 보관된 화면이라 그대로 두었다.
