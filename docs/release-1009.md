## 2. 화면별 적용 — "결론 한 줄 → 큰 숫자·등락 → 끌어서 보는 그래프 → ⓘ 설명 → 다음 행동"

### 2-1. 단지 허브 · 지도 단지 패널
- **첫 화면 대표가**: 가장 많이 거래된 평형의 최근 6건 평균(AI 분석과 같은 함수) — 헬리오시티 "30.9억 ▲15.8% 전월비"(평형이 섞인 월평균:
  8월 84·110㎡ 4건 vs 7월 39·59㎡ 포함 11건) → "**29억 6,750만원 ▼0.8%** · 2026.01 거래 6건 평균보다 2,333만원(0.8%) 내렸어요". 한 건 단지는
  "6억 1,000만원 · 2026.04.07 계약 · 16층 · 한 건 거래라 평균이 아니에요". 비교할 거래가 모자라면 등락을 적지 않는다.
- **실거래가 추이**: 평형 탭(최대 4, 거래 3건 이상인 달이 2개 이상일 때만) + 훑는 그래프 + 출처(국토부 · 해제 신고 제외 · 최근 1~2개월은 신고 중).
- **한 건 단위 실거래 목록**(새로): 계약일 · 전용(㎡/평 설정) · 층 · 거래가(정밀 표기). 요약 8건 + 실거래 탭 전체.
- 단지 정보 격자(있는 값만), ⓘ 8종, "시세" → "실거래", "AI 요약" → "한눈에 요약 · 공공데이터 자동 계산"(AI 가 쓴 글이 아니었다).
- "전월 대비"라 적고 실제로는 직전 거래월과 비교하던 표(단지 53%에 빈 달) → 앞 줄이 정확히 전달일 때만 "전월 대비", 아니면 "26.02 대비".
- 검색 제목·설명·공유 카드·FAQ(JSON-LD)·임베드 숫자를 첫 화면 대표가와 일치(공유 카드가 ▲15.8% 인데 들어오면 ▼0.8% 이던 모순 제거).
- 관심 단지: 켤 때 하트 팝, 끌 때 "관심 단지에서 뺐어요 · 되돌리기"(실제 다시 등록), 저장 중 표시.
- 지도: 패널 추이 그래프·월별 줄·"이 동네 대비" 등락색 정정, 지도 말풍선·지역 정보창 raw hex·"▲0.00%" 제거, 다크 모드 말풍선.

### 2-2. AI 분석 · 분석 도구
- 결과 그래프 훑기(월평균 · 거래 n건 · 같은 평형 m건, 적은 달 "참고용", 시나리오 구간은 "가정 — 예측 아님"), 머리 큰 숫자 + 기준 적힌 등락.
- 결과 칸: 가격은 Won, 지역 변화는 ▲▼ + "1년 전(2025.08) 대비", ⓘ 28개(계산 상수를 import 해 설명과 계산이 어긋나지 않게 테스트로 잠금).
- 비교: "338,000만" → "33억 8,000만", 레이더 누르면 강조·실제 값, 빼기 → 되돌리기(다시 담기, 알림 값은 비어 있다고 사실대로).
- 시기 판단: 지수 훑기, 신고 중인 달은 등락 대신 "집계 중(9/30까지 신고)", 시나리오: 결과 9곳 TweenNumber · 부담률 기준을 계산기(30/40%)와 통일.
- 온도: 주간 기록 훑기(세로축 0~100 · 중립 50 기준선), 갭·가격: 등락 표준·억 표기("1억 2,000만/평")·ⓘ.

### 2-3. 홈 · 지역 · 보고서 · 관심 단지
- 홈 지역 카드: 서울 25개 구 부동산원 스냅샷이 비어 1장만 뜨던 것 → 신고 기한이 지난 달의 월 집계로 채우고, 등락은 브리핑과 같은 부동산원 지수 기준.
  건수는 제 달·원천과 함께("7월 거래 189건 · 국토부"). 섹션 이름 "지역 시세" → "지역 동향"(실거래 평균이 섞여 있어서).
- 지역 화면: 첫 카드가 전부 "—"이던 것 → 결론 "시세 지수가 전월보다 0.6% 올랐어요" + 칸 4개(지수·평균 매매가·전세가율 %p·거래량, 칸마다 기준).
  추세 카드는 지수·전세가율·거래량 탭 + 훑는 그래프. 시장 온도 ⓘ 를 실제 계산(`computeMarketTemp`)과 같은 말로.
- 월 리포트: 신고 중인 달은 등락·상승/하락 상위를 숨기고 "신고 기한(10/30)까지 늘어요", 완결된 달끼리는 **두 달 모두 집계된 지역만** 비교
  ("3월 35.4% 늘었어요" → 공통 217곳 기준 19.0%). "평균가 변동" → "평당가 전월 대비"(DB 함수 정의 확인) — 리포트·FAQ·RSS·개발자 문서 모두.
- 관심 단지: ✕ → 목록에서 먼저 빼고 5.5초 뒤 삭제, 그 안에 되돌리면 서버는 그대로(알림 기준가 유지), 화면을 떠나면 바로 확정.
- 주간 다이제스트(화면·메일): 모르는 변동 "— 0.0%" → "변동 미상".

### 2-4. 계산기 · 여정 · 게임 · 노트 · 매물 · 공용 액션 버튼
- 계산기: 결론 "이 집은 최대 3억 3,600만원까지 대출받을 수 있어요 · 규제지역 · 무주택 LTV 40% 기준", 결과 숫자 굴러감, 돈의 구성 막대(합 100%),
  ⓘ 10개(LTV·DSR·취득세·중개보수 — 근거 법령·시행일), 모바일 하단 결과 요약 고정. 생애최초 LTV 80% 가 6억을 넘으면 "금액 한도(도입 당시 6억원)는
