- 메뉴: 보는 주기 3그룹 22줄 → "오늘"(대시보드 · 운영·공지) + 일의 종류 5묶음(회원·콘텐츠 / 데이터 / 매출·결제 / 유입·성능 / 도구). 묶음은 접혀 있고 지금 화면이 든 묶음만 열린다. 화면 22개는 그대로(주소 변경 없음).
