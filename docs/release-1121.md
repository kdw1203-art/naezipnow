# 1121 — 기능 통폐합 1단계 · 3단계

소유자 2026-11-09: 통폐합 추천의 1단계 · 3단계 표를 붙이고 "위 두 단계만 진행해줘 · 변경 전후 이미지". 1120 위에 얹는다.
DB · 가격 · 결제 · 심사 화면 변경 없음. **주소는 하나도 지우지 않았다**(색인 · 공유 · 외부 링크 유지) — 같은 일을 하는 화면들을 "한 화면의 탭"으로 잇고
메뉴 · 입구를 줄였다(지역 화면 RegionTabs 와 같은 방식 · 공용 `SectionTabs` + `lib/nav/section-tabs`).

## 1단계
- **비교**: 단지 짝 비교 · 노트 회차 비교 · 매물 비교함 머리에 같은 탭 줄 [단지 | 노트 | 매물]. 후보 단지 비교(/analysis/compare · 내가 담은 단지 표)는
  단지 탭 안 링크 "내가 담은 후보 단지 비교 ›"(담기 · 비교 조회가 따로 돌아 화면은 유지).
- **계산기 허브**: 계산기 탭 줄에 "시장·대출 시나리오" 칸(주소 /analysis/scenario 그대로 · 시나리오 화면 머리에도 같은 계산기 줄).
  탭 줄 아래 "이어서 · 결정 카드 · 내 집 마련 여정 · 실거래가 게임" 한 줄.
- **실거래 리포트**: 월간 리포트 · 주간 다이제스트 머리에 [월간 | 주간] 탭.
- **지도 2D | 3D**: 메뉴의 "3D 지도" 줄 삭제 → 지도 단지 판 아래 "3D로 보기"(서울 · 지번 주소에서 동을 찾을 때만) · 3D 화면 왼쪽 판에 "2D"(같은 지역 지도로).
  단지 · 동 화면의 기존 "3D로 보기"는 그대로.

## 3단계
- **지역 종합 탭**: 지역 탭 줄에 "임장 가이드" 칸(/imjang/[실거래 구간 슬러그] · 실거래 구간 탭이 있을 때만) · 임장 가이드 화면에도 같은 탭 줄.
  (전월세 /rent 는 1101 부터 이미 탭.)
- **가이드**: 가이드 · 임장 가이드 · 계약 · 규제 · 데이터 방법론 · 데이터 출처 머리에 [전체 | 임장 | 계약 | 규제 | 데이터] 탭(데이터 출처는 "데이터" 칸).
- **AI 입구**: AI 도구 실행은 AI 분석 허브(에이전트 포함) 하나. 내 정보는 "내 분석" 한 칸(AI 비서 · AI 분석 기록 · 결정 카드) —
  예전엔 비서는 결정 카드 옆, 분석 기록은 포인트 칸 안에 흩어져 있었다.

## 하지 않은 것(다음에)
- 리포트의 "지역별" 탭: 지역을 골라야 하는 화면이라 지역 화면 탭(월간 리포트)으로 이미 닿는다.
- 지도 화면 위쪽에 상시 [2D | 3D] 단추: 3D 는 동 단위라 지도가 동을 알 때(단지 판)만 단추를 둔다.
