# release-1207 · 전국 정비구역 경계 지도 · 매월 갱신

소유자 2026-11-22: "지도에 정비구역 표시는 12월까지 다 수집되도록 하고 한 달에 한 번 업데이트".

## 무엇을
- **서울**: 서울시 「의제처리구역 위치정보」(OA-20957 · 2,336 도형) 그대로(public/data/seoul-zone-shapes.json).
- **서울 밖(전국)**: 서울 밖은 정비구역 경계 공개 파일이 없다. 국토교통부 도시계획정보(UPIS)를 브이월드 2D 데이터 API 로 받는
  「지구단위계획구역」(LT_C_UPISUQ161) 중 이름(dgm_nm)에 재개발 · 재건축 · 정비구역 · 촉진 · 주거환경 · 도시환경 이 든 것 —
  정비구역을 지정할 때 함께 결정되는 경계라 거의 겹치지만 같은 것은 아니다(화면 출처 줄에 "참고 경계"로 적는다).
- 꼴은 서울 도형과 같다(ZoneShape) — 지도의 구역과 이름이 맞으면 진행 색으로, 아니면 구 단위로 확대했을 때 옅은 회색 점선(지정 이력).

## 어떻게
- `lib/redevelopment/vworld-zone-shapes` — 정규화(가장 큰 바깥 고리 · 꼭짓점 120개 상한 · 소수 5자리) · 서울(시군구 11…) 제외 · 분류 코드.
- `GET /api/redevelopment/vworld-shapes` — 한 달 서버 캐시(unstable_cache · 태그) + CDN 하루. 실패는 캐시하지 않는다(반쪽 결과가 한 달 굳지 않게).
- **매월 갱신**: `/api/cron/redev-zone-shapes-refresh` — 매월 1일 03:17 KST. 태그를 비우고 다시 받아 수를 수집 기록(redev-shapes)에 남긴다.
- **12월 전 첫 수집**: 배포 뒤 지도 첫 요청(또는 배포 직후 한 번 호출)이 바로 받는다 — 12월 1일을 기다리지 않는다.
- 지도 두 곳(정비사업 지도 · 통합 지도): 서울 도형을 먼저 그리고 전국 도형을 뒤따라 붙인다.

## 한계
- 지구단위계획구역 이름에 정비사업 낱말이 없는 정비구역은 빠진다. 반대로 해제된 구역의 지구단위계획이 남아 있으면 들어올 수 있다(이력 회색으로 그린다).
- 서울 OA-20957 은 파일 자료라 매월 자동 갱신이 아니다(서울시가 새 판을 올리면 파일 교체).
- 브이월드 키는 운영 서버(icn1)에서만 쓴다 — 해외 IP 는 브이월드가 막는다.
