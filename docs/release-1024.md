## 3. 단지 상세 v2(담당 R, `app/complex/[id]/**`)
머리(흰 PageHead · 관심·공유 · 사실 줄 "국토교통부 실거래 YYYY-MM 부터 · 매매 N · 전월세 N · 최근 계약") → 개요 스트립 8칸 → 타입 탭(폰 sticky) → 매매|전세|월세 → 기간 칩 → 추이 그래프(월 중앙값 선 + 거래량 + ▲▼, `TxTrendChart`, `next/dynamic`) → 최근 실거래 표 → 전세가율·갭 → 관리비(있을 때) → 학교·지하철(있을 때) → 임장노트·Lab·AI → 인근 단지. 데스크톱 레일 `ComplexRail`(요약 4칸·노트 쓰기·비교·호가 점검·인근·AI 브리핑). 폰 하단 행동 바 유지. 네이비 히어로·워터마크·지표 4칸·InfoGrid·상단 행동 줄은 걷음. 데이터 로더·캐시·revalidate·JSON-LD·`#ai-summary`·FAQ·호가 점검·5탭 전부 유지.
다르게 한 것: 전세·월세 그래프와 갭은 전 타입(전월세 로더가 면적을 안 읽음 — 다음 차수) · 준공은 연도만(월 데이터 없음) · 해제 행은 로더가 `is_cancelled=false` 만 읽어 아직 안 나옴.

## 4. 원룸·오피스텔 동네 실거래(담당 S, `app/rent/**`)
`/rent`(수도권 시군구 목록, 건수는 있을 때만) · `/rent/[region]?type=officetel|rowhouse|house&dong=&area=s|m|l`(replaceState + refresh). 월세 요약 3칸 → 보증금×월세 산점(서버 SVG) → 최근 계약 표 → 전세 → 동 칩 → 사실 한 줄. 0행이면 "수집 전" 사실 문장 + noindex, 사이트맵은 행 있는 지역만. 동네 홈 머리에 "원룸·오피스텔 실거래 월세 ›"(수도권만).

## 5. 홈
칩 줄 + "처음이라면 ⓘ" 한 줄(`coverage` 슬롯). 폰은 줄바꿈 대신 한 줄 가로 스크롤("바로 보기" 라벨은 폰 숨김).
