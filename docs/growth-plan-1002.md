## 2. 1002 가 코드로 한 일

### 유입 도구
- **`/admin/promo` 홍보 킷**(관리자 메뉴 "홍보 킷"): ① 유입 30일을 채널(검색·AI·소셜·커뮤니티·직접)로 접어 보여 준다(조회 실패는 실패라고 표시). ② UTM 유입 표(붙인 링크가 실제로 데려온 세션). ③ 채널별 "이번 주 실행" 카드 5장(네이버 블로그·카페/커뮤니티·구글·AI 검색·카카오 공유) — 외부 링크와 한 줄 규칙. ④ **단지 글 팩** 최대 3단지: 최근 30일 검색·AI 로 들어온 단지 + 거래 많은 단지 순으로 골라, 네이버 블로그 본문(면적별 평균·거래 건수·임장 체크포인트·출처·투자 권유 아님)과 카페용 5줄 글, 해시태그, UTM 링크(`utm_source=naver&utm_medium=blog&utm_campaign=complex-2026w38`)를 붙여넣기 완성본으로 만든다. 수치는 국토교통부 신고분 실측·1시간 캐시. 소스가 실패한 섹션은 `missing` 에 적히고 빠진다.
- 블로그 팩(`/admin/blog-pack`) 링크 3곳에 UTM(`weekly-2026w38`) — 이제 `/admin/traffic`·`/admin/promo` UTM 표에서 효과가 보인다.
- `llms.txt` 의 동네 홈 개수가 "62개"로 굳어 있던 것을 카탈로그 실제 수(107)로.

### 홈(온 사람이 첫 화면에서 다음 행동을 찾게)
- 검색 아래 **"예산으로 찾기"** 칩(3·5·7·10억 이하 → `/map?region=…&priceMax=N`). 검색어가 없는 사람에게 두 번째 입구.
- 지역 시세 카드 **마지막 집계 폴백**: 실시간 스냅샷이 실패하거나 0건이면 `market_region_monthly`(월별 실거래 평균, 거래 10건 이상인 최근 달)로 카드를 그리고 "마지막 월 집계를 보여드려요" 한 줄을 단다. 둘 다 실패해야만 예전의 "불러오지 못했어요".
- **최근 본 단지 중복 제거**(공작아파트 2번): 이름 id ↔ kapt id 짝만 합친다(kapt id 끼리·지역 없는 기록은 합치지 않는다 — 동명 단지 보호).
- AI 입구에 "로그인 없이 단지 데이터 진단 미리보기 →"(`/analysis/ai/ai-diagnosis` 는 2단계까지 비로그인 실데이터).

### 운영
- 비밀번호 찾기: "메일을 보냈습니다" 아래 "10분이 지나도 오지 않으면 고객센터에 계정 문의" 링크(`/support?category=account&topic=password-reset`, 제목·본문 미리 채움 — 이메일은 주소창에 싣지 않는다). API 응답에 발송 경로를 싣지 않는다(리뷰: 경로 = 계정 존재 여부 유출).
- 관리자 고객 문의: 결제·환불 문의 본문의 "주문번호: …" 를 읽어 **"결제 관리에서 주문 보기 · 환불 처리 →"** 링크. `/admin/payments?order=…` 는 그 주문이 최근 20건 밖이어도 찾아 맨 위에 올린다(환불 버튼 포함, 조회 실패와 없음을 구분).
- 단지 실거래 조회 2곳에 `order by contract_ym desc` — PostgREST 1,000행 상한에 걸리는 대단지에서 "최근 12개월"이 잘리지 않게(홍보 글 수치의 근거).

## 4. 소유자가 한 번만 하면 되는 설정 (순서대로)

1. **RESEND_API_KEY** — Vercel 환경변수(`re_` 로 시작). 이메일 발송 0건이 30일째다: 영수증·비밀번호 재설정·문의 답변·주간 다이제스트가 전부 이 키 하나에 걸려 있다. 키는 Vercel 대시보드에만 넣는다(채팅·코드 금지).
2. **네이버 서치어드바이저** (searchadvisor.naver.com) — naezipnow.com 속성은 이미 인증됨(HTML 태그 2개 배포 중). 요청 → 사이트맵 제출 `https://naezipnow.com/sitemap.xml`, RSS 제출 `https://naezipnow.com/feed.xml`. 제출 뒤 "수집 현황"에서 수집 요청 오류가 0인지 주 1회.
3. **Google Search Console** — 색인 → 페이지: "색인 생성됨" 수와 "발견됨 – 현재 색인 생성되지 않음" 수를 적어 둔다. 단지 페이지가 후자에 많이 쌓이면 다음 판에서 사이트맵 우선순위(거래 건수 기준)를 조정한다.
4. **NEXT_PUBLIC_KAKAO_JS_KEY** — 노트 카드의 카카오 공유 버튼이 키 없이는 아예 그려지지 않는다(정직 원칙). 카카오 개발자 콘솔 JavaScript 키(공개 키라 노출돼도 됨) → Vercel 환경변수 → 재배포.
5. kosis(통계청) API — `skipped series=0` 이 이어진다. data.go.kr 활용신청 승인 상태 확인.
