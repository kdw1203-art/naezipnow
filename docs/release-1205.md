# release-1205 · 이어서 — 배포 빌드 서비스 키 · 온비드 상한 · 토론 판 빈칸

release-1201 D · E 절에서 결정 없이 할 수 있는 셋.

1. **배포 빌드에 서비스 키**(#49): `vercel pull` 은 Sensitive env 를 빈 값으로 내려줘, 배포 워크플로의 운영 빌드가 서비스 키 없이 돌았다 —
   미리 그리는 화면(지도 · 청약 · 단지 목록 등)이 "서비스 클라이언트 미구성" 빈 데이터로 구워져 첫 재검증까지 남았다(/apply "불러오기 실패"의 뿌리).
   빌드 직전에 GitHub Secret 값을 `.vercel/.env.<target>.local` 에 넣는다(서비스 키 형식일 때만 · .vercel/output 에는 안 실림).
2. **온비드 상한**(#52): 시도당 5쪽(500건) → 10쪽(1,000건). 시도를 셋씩 동시에 돌려 120초 안에. 쪽 사이 같은 물건(목록 밀림)은 키당 한 줄로 —
   한 번의 upsert 에 같은 키가 둘이면 Postgres 가 그 시도 전체를 버린다.
3. **홈 실시간 토론 PC**(#44): 글 칸이 왼쪽 순위 목록 높이까지 늘어 글이 적으면 속이 비었다 → 홈에서는 두 칸이 각자 내용 높이(토론 화면은 그대로).
