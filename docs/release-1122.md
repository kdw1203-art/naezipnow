# 1122 — 다른 지역 찾기(검색 · 필터 · 지도) · 임장 가이드 지도 고르기 · 관리자 · 마이 · 회원가입 · 주간 다이제스트 메일

소유자 2026-11-09~10: "목록이 많으면 지도 · 필터 · 검색으로 찾도록, 하나만 있다면 지도 · 필터 · 검색으로 다른 지역도 찾고 분석할 수 있도록" ·
"관리자 페이지와 마이페이지 등도 개선" · "회원가입과 주간 다이제스트(메일) 업데이트". 1121 위에 얹는다. DB · 가격 · 결제 · 심사 화면 변경 없음.

## 다른 지역 찾기(지역 화면 일곱 곳 공통)
- 지역 탭 줄 아래 "다른 지역 찾기 · 검색 · 지도" 단추 — 누르면 그 자리에 지역 고르기 지도(검색칸 · 시/도 필터 · 실지도 말풍선 107곳)가 펼쳐진다.
  고르면 **지금 보던 탭 그대로** 그 지역으로(개요 · 동네 · 월간 리포트 · 시장 온도[기록하는 지역만] / 실거래 구간 · 전월세 · 임장 가이드는 개요로).
  지도 SDK 는 펼칠 때만 받는다. `lib/region/region-switch` · `RegionSwitcher`.

## 임장 가이드 목록(/imjang)
- 48칩 벽 → 지역 고르기 지도(말풍선 = 실거래 건수 · 시/도 필터 · 검색) + 닫힌 "전체 목록 48곳"(크롤 경로).
  카탈로그 좌표에 맞는 41곳이 지도에, 나머지는 전체 목록에.

## 관리자
- 빈 상태(tone="admin") = 한 줄(작은 아이콘 · 제목 · 설명 | 오른쪽 링크). 대시보드 "할 일 없음" 여섯 칸이 첫 화면을 다 채우던 것 → 높이 약 1/3.
  관리자 화면 27곳에 같은 꼴.

## 마이
- 격자 밖에 전폭으로 붙던 세 칸(저장한 글 · 팔로우 새 노트 · 내 분석)을 2열 격자 안으로 — 왼쪽(활동) 끝 / 오른쪽(관리) "더 보기" 위.

## 회원가입
- 단계 줄 아래 "가입하면 쓰는 것" 사실 세 칸(임장노트 저장 · 관심 단지 10곳 알림 · AI 분석 누적 3회 — lib/subscriptions/plans 의 무료 한도 그대로).

## 주간 다이제스트 메일
- 시장 요약: 세 열 표 → 2칸 격자 숫자 칸(지역 · 큰 가격 · 등락 알약) + 기준 한 줄. 뉴스: 순번. 이웃 글: 한 줄 칸 + 동네이야기 링크.
  단추 전폭 + 아래 "지역 시세 분석 · 임장노트 쓰기". 제목 · (광고) 표기 · 수신거부 안내 · 본문 자료는 그대로.
