주소가 아니라 id 를 받으므로 남의 그림을 대신 받아 주는 프록시가 아니다(내부망·IP 리터럴 주소는 받지 않는다 — lib/news/thumb.ts).
CDN 30일(`s-maxage=2592000`) · 브라우저 1일. 못 받으면(차단·삭제·8초 초과·12MB 초과·이미지 아님) 404 — CoverImage 가 선 아이콘 칸으로
돌아가는 종전 규칙 그대로. 404 도 CDN 1시간 캐시라 죽은 원본을 매 조회마다 두드리지 않는다. 속도 제한은 분 240회(목록 한 장 40행).

호출부 다섯 곳이 `newsThumbPath(id)` 를 src 로 쓴다 — 뉴스룸 목록(NewsListClient) · 많이 본 레일 · 홈 뉴스룸 띠(HomeTownBlock) ·
주제 목록(tag/[tag]) · 다이제스트(DigestThumb). 원본 주소가 없는 글은 종전처럼 요청하지 않는다. 기사 상세 머리 사진(NewsHero)·OG·메일은 원본 그대로.

실측(폰 390 · 목록 끝까지 스크롤): 전(운영) 이미지 36장 11,881KB → 후(로컬 1079 빌드) 39장 171KB(**70분의 1** · 장당 2.5~9KB · 서버가 받으니 브라우저에서
