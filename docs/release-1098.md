## 깜박임 — 왜 그랬나

공유 캐시(ISR) 화면은 보는 사람을 몰라 광고 카드(배너 · 자사 안내)를 HTML 에 실어 보내고, 브라우저가 하이드레이션 뒤 세션을 읽어 유료
플랜이면 숨겼다(`AdFreeGate`). 그 사이 광고 카드가 **한 번 그려졌다 사라진다** — 유료 플랜(소유자 계정 enterprise 포함)은 화면을 열 때마다
광고판이 깜박였다. 비회원은 세션 조회가 없어 깜박이지 않는다(운영 실측 · 10초 동안 변화 없음).

| | 전 | 후 |
|---|---|---|
| 유료 플랜 · 공유 캐시 화면 | 광고 카드 그려짐 → 세션 조회(수백 ms) → 사라짐 | 판정을 `localStorage(nz_ad_free)` 에 기억 · 그리기 전 인라인 스크립트가 `html[data-ad-free="1"]` → CSS 가 광고 자리를 처음부터 비움 |
| 관리자(소유자) | 유료 플랜이라 광고가 깜박였다 | 광고 자리를 확인해야 하므로 유료 플랜이어도 그대로 본다(`adFreeForViewer`) — 깜박임 없음 |
| 로그아웃 뒤 | — | 첫 화면이 세션을 읽어 "0" 으로 되돌린다 · 세션 조회 실패(쿠키 힌트 있음)는 기억을 건드리지 않는다 |

첫 방문(기억 없음)은 종전처럼 한 번 숨긴 뒤 다음 화면부터 비어 있다. 로컬 실측: 기억이 있으면 360ms(HTML 파싱 중)에 광고 자리 4곳이 모두
`display: none` — 그려지기 전이다.

## 광고 배너 공간 — 상단 띠 배너

| 항목 | 내용 |
|---|---|
| 자리 | 허브 머리 아래 한 줄 — 홈(검색 묶음과 오늘의 시장 사이) · 뉴스룸 · 동네 · 실거래 구간(/tx) · 동별 실거래(/dong) · 단지 비교 · AI 분석 허브 |
| 크기 | 폰 64px · PC 90px(높이를 CSS 가 미리 잡아 그림이 늦어도 본문이 밀리지 않는다) · 1200×90 권장 · PC 는 비율 유지 · 폰은 왼쪽부터 64px 로 잘라 보인다 |
| 내용 | 관리 › 배너에 **띠 배너 이미지 URL** 을 넣은 배너(새 입력 + 미리보기). 이미지 없는 배너는 종전 카드 자리에만 · 이미지 배너는 띠 자리에만(같은 배너 두 번 금지) |
| 라벨 · 링크 | "광고" 라벨 고정 · CTA 는 오른쪽 아래 · 바깥 링크는 새 탭(nofollow) · 클릭 집계(AdSlotTracker) |
| 비었을 때 | 아무것도 그리지 않는다(빈 상자 금지). **관리자에게만** 점선 자리 "상단 띠 배너 자리(홈) · 등록된 띠 배너 없음" + 배너 등록 링크 |
| 유료 플랜 | 카드 자리와 같은 규칙(숨김 · 관리자는 본다) |

DB placement 값(home · community · market · inspection · global)은 CHECK 제약이 있어 그대로 쓴다 — 띠 배너는 "이미지가 있는 배너"다.
