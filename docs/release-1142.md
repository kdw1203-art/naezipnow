# 1142 — 테마 색을 로고 색에 맞춤 · 가입 두 걸음

## 테마 색(소유자 2026-11-11 "테마색상도 로고랑 로고이미지색상이랑 맞춰줘")
로고 = 네이비 #0B2545 + 주홍 #C8442B. 사이트 주색은 밝은 파랑(#1D4FD8)이라 로고와 따로 놀았다 → 주색을 로고 남색 계열로.

| 토큰 | 전 | 후 |
|---|---|---|
| --primary (글자 · 링크 · 테두리) | #1d4fd8 | #1b4b91 |
| --primary-strong | #16389c | #0b2545 (로고 네이비) |
| --primary-soft | #edf2fe | #eaf0f9 |
| --primary-fill (채운 단추) | #2f62e2 | #3468bf |
| 다크 --primary / strong / soft | #5b8bff / #86a9ff / #1a2540 | #7aa5ea / #a6c3f3 / #17243b |

- 주홍(--brand-red)은 그대로 — "지금" 신호 · 로고 온점.
- 코드에 박혀 있던 같은 파랑(공유 이미지 · 메일 · 지도 · 차트 28개 파일, rgba 포함)도 같이 바꿨다.
- 대비: check-contrast-tokens 라이트 · 다크 57조합 통과. 흰 글자 대비 주색 8.5:1 · 채운 단추 5.4:1.
- 상승(빨강) · 하락(파랑) 시세 색, 사용자가 고르는 다른 테마(보라 · 청록 등), 관리자 다크 콘솔 색은 그대로.

## 가입 두 걸음
필수 칸이 9개로 늘어 한 화면에 다 세우던 것 → 1 계정(이름 · 이메일 · 비밀번호) → 2 기본 정보 · 동의. 같은 폼 · 같은 단추("다음 · 기본 정보" → "가입하고 노트 쓰기"), "이전 · 계정 고치기"로 돌아간다. 입력값은 걸음을 오가도 남는다.

확인: 빌드 통과 · 단위 테스트 2,636 · 홈 486/495KB. 전후 캡처(전 = 운영 · 후 = 로컬).
