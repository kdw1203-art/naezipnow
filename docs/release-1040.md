## 2. 뉴스 → 지역 연결

- 원인: 자동수집 뉴스의 `region` 열은 시·도("서울"·"경기"·"수도권")이거나 비어 있는데, 지역 허브는 시·군·구 단위다 → region 만으로는 풀릴 수 없었다(1,000건 중 100건).
- 시·군·구는 수집 메타에 있다: `automation_meta.geo.sigungu`(글자 또는 배열) · `geo.places` · 태그 · 제목.
- `lib/news/region-link.ts` `resolveNewsRegion`: region → geo.sigungu → geo.places → 태그 → 제목 순. 부분 일치 없음 · "중구"·"서구"·"강서구"처럼 겹치는 이름은 시·도가 있어야 · 지역이 셋 이상이면 종합 기사로 보고 풀지 않는다 · 동네 이름(압구정·목동·성수 …)은 한 구 안에만 있는 것만.
- 쓰는 곳: 뉴스 상세의 "○○구 시세 보기 ›"(링크 글자도 풀린 구 이름) · 관리 화면 연결률(같은 해석기 — 재는 법과 그리는 법이 같다).
- 실측(2026-10-06 · DB 1,000건): 메타의 시·군·구와 장소만으로 **336건 이상**(하한 — 카탈로그 일부만 대조한 SQL). 제목만으로는 공개 뉴스 698건 중 136건.
- 관리 화면 패널: 연결 · 시·도만 · 지역 없음을 따로 센다(시·도 기사·전국 기사는 연결 실패가 아니다) + 읽은 자리별 건수.
