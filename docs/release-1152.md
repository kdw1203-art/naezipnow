# 1152 — 서울 정비구역을 지도에(대표 지번 위치)

소유자 2026-11-11 "지도에 반영할 수 있도록 — 목록으로는 타 사이트에 밀려".

## 바뀐 것
- 전국 정비구역 목록(국토교통부 · 좌표 없음)의 서울 구역에 위치를 붙여 지도(`/map` 정비사업 레이어 · `/redevelopment`)에 싣는다.
  - 위치는 **지어내지 않는다**: 서울 도시계획 결정 조서(UPIS)에서 같은 자치구 · 같은 구역 이름의 "위치(대표 지번)"를 찾아 지오코더에 묻고, 돌아온 주소가 그 자치구일 때만 찍는다.
  - 이름이 지번인 구역("응암동700번지일대")은 그 지번을 쓴다. 못 찾은 구역은 목록(`/redev-list`)에만 남는다.
  - 찍히는 점은 대표 지번 위치다(구역 경계 아님) — 안내창 요약에 적는다.
  - 공표 단계 · 유형 · 공급 예정 세대수가 이름표 · 걸러 보기에 그대로 쓰인다. 주거환경개선은 지도 분류에 없어 싣지 않는다.
  - 손으로 정리한 40곳과 같은 구역은 건너뛴다(점 두 개 방지).
- 새 작업 `/api/cron/redev-zone-locate` — 매주 월요일(전국 목록 적재 15분 뒤). 한 번에 90초까지 묻고, 남으면 다음 실행이 잇는다.
- 1151 포함: 분류 값 순번 떼기 · 수집 뒤 서울 지도 바로 갱신.

## 확인
- 단위 시험 2,650 통과 · 전체 빌드 통과. 운영 자료로 이름 맞추기 표본 18건 눈으로 확인(모두 같은 구역).
- 배포 뒤 `https://naezipnow.com/api/cron/redev-zone-locate` 를 열면 결과 숫자가 나온다(예산 소진이면 한 번 더).

## 남은 것
- 구역 경계(다각형) — 공개 좌표 자료 미확인.
- 서울 밖 구역 위치 — 대표 지번 자료가 서울 조서뿐이다.
