# 1052 — 고도화·기능 개선 묶음(58가지)

소유자 지시(2026-10-09): "지금까지 작업한 내용에 대해서 고도화 및 기능개선 등의 작업을 진행해줘 50가지 정도 / 변경 전후의 이미지도 보여줘".

1051 위에 누적. 가격·상품·요금제·결제 화면 변경 없음(검사 check:review-freeze 통과). DB 변경 없음(1051 표 그대로 씀).
범위: 1048~1051 에서 만든 것(실시간 토론 · 다요인 분석 · 노트/AI 펼침 · 홈 정리 · 전문가 · 단지 주변 지도 · 성장 기록)을 다시 읽고
고장·과장·접근성·속도 순으로 고쳤다. 고르는 기준: 사실과 다르게 보이는 것 > 데이터가 새는 것 > 쓰다 막히는 것 > 다듬기.

## 1. 실시간 토론(1051) — 18가지

1. 지역을 빨리 바꾸면 늦게 온 앞 지역 응답이 새 지역 칸을 덮어 뼈대만 남던 것 — 요청 표(가장 최근 지역만 받음) · 앞 요청 취소.
2. 고른 지역이 이 탭 순위 밖이면 목록 맨 위에 "이 순위 밖" 고정 줄 · 지역을 아직 안 골랐으면 "지역 선택 없음".
3. 지역 찾기 칸(송파 · 분당 · 인천) — 찾는 중엔 탭 순위 밖 지역도(순위 있는 것 먼저).
4. 단지 붙이기 지역 판정 — 시·도가 다르면 같은 구 이름이어도 다른 지역(부산 강서구 ≠ 서울 강서구 · 긴 구 이름도 겹쳤다). "광주시"(경기)는 시·도로 읽지 않는다.
5. 지역 뉴스 낱말 — 지명이 아닌 낱말 속 지역 이름 제외: 성수기(성수) · 경상수지·수지타산(수지) · 1분당(분당) · 여의도 정가(여의도). 토론 소식 · 다요인 분석 뉴스 · AI 지역 뉴스가 같은 규칙.
6. 자동 소식 — 지수·거래 · 뉴스 · 임장노트를 조각마다 캐시. 예전엔 뉴스 하나가 실패하면 지수·거래까지 통째로 비었다 → 실패한 조각만 빠지고 "일부 소식 불러오기 실패".
7. 왼쪽 순위도 보이는 동안만 다시 받는다(예전 2분마다 무조건) · 다른 탭에서 돌아오면 글을 바로 한 번.
8. 올린 즉시 왼쪽 글 수 +1 — 순위 응답은 CDN 30초 캐시라 다시 받아도 옛 수였다.
9. 아래로 내려 읽는 중 새 글이 오면 "새 글 N개 ↑" 단추(누르면 맨 위로).
10. 마지막으로 본 지역 기억(이 브라우저 · 홈과 토론 화면 공용).
11. 로그인 뒤 돌아올 주소에 고른 지역(/talk?region=…).
12. 지우기·신고는 한 번 더 확인("지울까요?") · 폰 누름 면 40px(데스크톱 24px) · 붙인 단지 칩 24px.
13. 글자 수 — 180자부터 "N자 남음" 경고 · 200자 빨강. 자르기는 글자(코드 포인트) 기준(이모지를 반쪽으로 자르지 않음).
14. 단지 찾기 칸 — 열면 바로 입력 · Esc 닫기 · "2자 이상 · 이 지역 단지만" 안내 · 같은 검색을 되풀이하던 의존성 수정.
15. 화면 읽기 — 목록 전체를 다시 읽던 aria-live 를 "새 글 N개" 한 줄로 · 실패 칸에 "다시 불러오기" · 폰은 지역을 고르면 글 칸으로 스크롤.
16. 관리 화면(/admin/moderation) — "실시간 토론 · 신고·숨김" 칸: 신고 1건 이상·숨김 글, 되살리기(숨김 해제 · 누적 0) · 지우기(두 번 누름 · deleted_at). API `PATCH /api/admin/talk`(관리자만).
17. 회원 탈퇴 접수 — 토론 글도 즉시 숨김(hidden_at · 취소하면 되살림). 1051 문서에 "탈퇴 시 파기 대상"이라 적었지만 접수 단계 숨김이 빠져 있었다. 접수 회신 메일·SOP 문서도 고침.
18. 지역 화면 오른쪽 — "○○ 실시간 토론" 한 줄(수도권 67곳만 · 클라이언트 JS 0 · 글은 토론 화면이 받는다).

## 2. 홈 — 4가지

19. 지역 동향 "기준 · 출처" — "거래 = 그 달 신고 건수(국토교통부)"는 카드(부동산원 월간이 기본)와 달랐다 → "카드 끝 표기 · 한국부동산원 월간 또는 국토교통부 신고".
20. 문구·글자 단계 — 브리핑 없음 "오늘 브리핑 없음 · 매매가격지수 갱신 뒤 표시" · 오류 "잠시 후 다시" · text-[12px] → t-sub.
21. 오늘의 한 줄 — 탭 키보드(화살표 · Home · End · 포커스 따라감 · 지금 탭 하나만 Tab) · tabpanel 연결 · "~예요" 문장 → 사실 낱말.
22. 서울 25개 구 막대 — 줄마다 링크인데 32px → 폰 40px.

## 3. 임장노트 — 10가지

23. 표·폰 격자 펼침 — 필터·정렬·검색으로 목록이 바뀌면 닫는다(펼친 줄이 다른 자리로 튀던 것).
24. 펼치면 펼친 카드가 화면 안에 들어오게(아래쪽 줄을 펼치면 카드가 화면 밖에 열렸다).
25. 접으면 그 줄로 초점 · Esc 로 접기 · 펼친 칸 role=region.
26. 표 "기록 점수" 머리를 누르면 점수 높은 순(공개 노트 "점수순" 칩과 같은 상태 · aria-sort).
27. 점수 막대 색 — 50점 미만을 시세 '하락' 색으로 칠하던 것 → 중립 회색. 경계(75 · 50)는 홈 배지와 한 상수(lib/notes/score-band).
28. 왼쪽 레일 지역 막대 — 지금 칩을 건 목록에서 센다(관심 지역 칩을 켜도 수가 그대로였다) · 지역이 비어 있는 노트가 제목 앞 6자로 '지역'에 섞이던 것.
29. 폰 보기(격자 · 피드 · 목록) 기억 — 데스크톱처럼.
30. 빈 상태·오류 문구를 사실 낱말로("구독 지역 노트 없음" · "○○ 불러오기 실패 · 잠시 후 다시").
31. 노트 상세 → 데이터 도구 — 노트에 이어진 단지 id 를 먼저 싣는다(노트 지역 표기 "서울 송파구 잠실동"으로 지은 id 가 단지를 못 찾던 경우).
32. 노트 상세 4축 — 채광·주차를 '시설' 점수로, 소음을 '입지' 점수로 메우던 것(작성자가 매기지 않은 감각 항목을 지어냄) 제거. 교통만 교통 점수. ⓘ 설명도 고침.

## 4. AI 분석 허브 — 3가지

33. 펼친 칸 단추가 할 일을 말한다 — "○○단지 종합 진단 열기 ›" · 단지 전이면 "단지 고르고 종합 진단 열기 ›".
34. 펼침 키보드 — 화면 안으로 · 접으면 그 도구로 초점 · Esc.

## 5. 다요인 분석(1048) — 6가지 · 계산식 2판

36. 최신 자료 날짜 — "2026.09" · "2026-08" · "202608" 을 글자로 정렬해 틀린 달이 나오던 것 → 숫자로 맞춰 비교 · 표기 통일(yyyy.mm).
37. 없는 값은 점수에 넣지 않는다 — 방향 낱말 없는 뉴스(예전 0점으로 반영) · 입주 예정 조회 실패(예전 0세대 → +1점) · 관심도 조회 실패(예전 "0건"). 공식 v2.
38. "쪽·강함" 경계 한 상수(SIGNAL_LEAN) — 판과 엔진이 다른 숫자를 써 0.3점이 판에선 "오름 쪽", 엔진에선 중립이었다.
39. 이름 — "AI 다요인 분석" → "다요인 분석 · 규칙 계산"(정해진 식으로 계산하는 값 — AI 판단이 아님). 방법론 문구·변경 기록(2판)도.
40. 미반영 이유를 줄마다 — 표본 적음 · 불러오기 실패(점선 경고) · 자료 없음, "반영 5/8(미반영 …)".
41. 요인 줄마다 "출처 · 기준 달" · 요인 이름 → 방법론 해당 칸(#signal-요인) · 허브 펼침에 "계산 방법 ›".

## 6. 전문가 — 8가지

42. 공개 API(/api/experts) — 운영자 검수 메모(verificationNote)가 공개 JSON 에 실리고 있었다 → 명시 화이트리스트 · 미인증 전문가 연락처·등록번호 null.
43. 근처 전문가 — 시·도가 달라도 같은 구 이름(중구·강서구)으로 이어 붙던 것 · 충북↔충남(앞 두 글자 비교) 수정.
44. 등록번호 형식 — "12345" 같은 숫자만 번호가 거절되던 것 · 서버도 같은 검사.
45. 변호사·법무사 거절을 서버에서도(등록 · 수정 · 관리자 등록 — 칭호·전문 분야·상호 낱말까지).
46. 신청서 임시 저장(이 탭 · 동의 칸 제외) · ?type= 로 분야 미리 고르기 · 분야 화면 "등록"에서 분야를 싣고 감.
47. 신청서 접근성 — 라벨 연결 · 오류 role=alert · 칩 묶음 이름.
48. 인증 배지 — 화면 읽기 이름 · 상세 화면 "검증 정보"로 링크 · 누름 면.
49. 분야 칩 — 0명 분야 숨김 · 별칭까지 세기("건축사" → "건축사·설계" 0명으로 보이던 것).

## 7. 단지 주변 지도 · 마이 · 성장 기록 — 8가지

55. AI 서술 월 예산 — 같은 한국 시간 달.
56. 유입 기록 — 계정별(이메일 해시) 완료 표시 · 실패는 탭당 한 번만 다시(4xx 는 끝) · 겹쳐 보내기 막기.
57. 관심 단지 저장 대기 — 가입 안내를 닫으면 대기도 지운다(나중에 엉뚱한 때 저장되던 것) · IndexNow 단지 제출 최신 순 + 잘림 표시.

## 8. 속도 — 1가지(+ 번들 정리)
