# release-1203 · 서울 전역 정비구역 · 처음이라면 위치 · 애플 디자인 컨셉

소유자 요청(2026-11-21): "재개발닷컴처럼 지도에 정비사업 관련 구역이 나오도록 서울권 전역 · 처음이라면은 검색 오른쪽 · 전체적으로 애플의 디자인컨셉".

## 1. 서울 전역 정비구역 (통합 지도 · 정비사업 지도)
- 자료: 서울시 「의제처리구역 위치정보」(OA-20957 · 2026-09) 도형 2,336곳 + 진행 목록 1,359곳(서울).
- 예전: 진행 목록과 짝지어진 도형만 그렸다 → 실측 **343곳만** 보였다.
- 이제: 나머지 **1,993곳**도 **옅은 회색 점선**(지정 이력 · 진행 여부 미확인)으로 그린다 — 자료에 끝난 구역이 섞여 있어 진행 중 색과 구분.
- 서울 전체 화면에서 2,000개를 한꺼번에 그리면 지도가 무거워져 **구 단위로 확대했을 때(화면 폭 ≤ 0.2°) 화면 안 것만**. 종류 · 단계 거르기를 걸면 이력 구역은 숨긴다.
- 범례에 "지정 이력 구역 · 진행 여부 미확인" 한 줄.

## 2. "처음이라면 ⓘ" — PC 는 검색 상자 바로 오른쪽(상자는 가운데 그대로), 폰은 폭이 모자라 칩 줄 끝.

## 3. 애플 디자인 컨셉 (토큰 — 전 화면 한 번에)
- 바탕 #f5f5f7 · 판 흰색 · 글자 #1d1d1f + 회색 셋 · 강조 파랑 하나(링크 #0066cc · 채움 #0071e3)
- 카드 모서리 18px · 그림자 거의 없이 얇은 선 · 머리 반투명 유리(saturate 180% + blur 20px)
- 네이비 판 → 애플식 검정 타일(#1d1d1f) · 채움 버튼은 알약 · 제목 자간 -0.022em
- 다크: 바탕 #000 · 판 #1c1c1e · 강조 #2997ff
- 대비: 본문 4.5:1 전 조합 따로 계산(최저 4.55) — text-3 를 #66666b 로 한 단계 진하게.
- 토큰(hex)은 토큰 구역(다크 블록 뒤)에, 규칙은 맨 끝 블록(토큰만) — append 규칙 그대로.

## 4. 광고 칸 — 스크립트가 막힌 경우(차단기) 8초 대신 3초에 접는다.

검증: tsc · 단위 테스트 2,696 · 대비 · 타입 램프 · 링크 · 아이콘 · 장식 컨트롤 린트 · 빌드 · 로컬 캡처(PC · 폰).
지도 도형은 이 환경에서 네이버 지도가 막혀 배포 뒤 운영에서 확인.
