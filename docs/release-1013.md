# 1013 — 뉴스 썸네일 · 리퀴드 목록 선 색 바로잡기

## 1. 뉴스 썸네일 (주인님: "뉴스는 이미지 파일이 있어야 할 것 같아")

- 뉴스룸(`/town/news`)과 주제 허브(`/town/news/tag/[tag]`)의 모든 기사 행 왼쪽에 72px 정사각 썸네일(`app/town/news/NewsThumb.tsx`).
  동네이야기 피드(FeedRow)와 같은 칸 크기다. 제목은 데스크톱 두 줄, 폰은 전역 한 줄 규칙.
- 사진은 원문 매체가 기사에 붙인 대표 이미지(og:image)다. 최근 수집분 1,061건 중 1,001건(94%)에 있다.
  우리 서버가 사진을 복사하거나 변환하지 않고 매체 주소를 그대로 건다(`/_next/image` 안 거침 → Vercel 이미지 비용 0).
  매체의 핫링크 차단은 우회하지 않는다(referrerPolicy 조작 없음).
- 사진이 없거나 매체가 막으면 같은 칸에 매체 이름을 적는다 → 행 높이가 늘 같다(v4 가 썸네일을 뺐던 이유가 "들쭉날쭉"이었다).
- 기사 상세의 큰 사진(NewsHero, "사진: 매체" 표기)은 전과 같다. 홈의 뉴스 3줄·동네 홈의 뉴스 한 행은 글자 행 그대로 둔다.
- `CoverImage`: 스크립트가 붙기 전에 이미 깨진 사진(첫 칸 eager)이 브라우저 "깨진 그림" 아이콘으로 남던 문제 — 마운트 때 한 번 확인해 폴백으로.

## 2. 리퀴드 목록 선 색 (1012 에서 들어간 버그)

- `--line` 은 없는 토큰이었다(선 색은 `--border`). 없는 변수를 섞은 `color-mix` 가 통째로 무효가 돼
  행 사이 선은 글자색(짙은 남회색)으로, 판 테두리와 유리 카드(`--glass-border`) 테두리는 아예 사라졌었다.
  세 곳을 `--border` 로 고치고, `tests/unit/css-vars-1013.test.ts` 가 "정의 안 된 변수를 fallback 없이 쓰는 곳 0"을 지킨다.

## 3. 1012 배포 사고와 보완

- 1012 적용 스크립트가 PowerShell `Copy-Item`/`Test-Path` 로 파일을 옮겼는데, 두 명령은 경로의 `[ ]` 를 와일드카드로 읽는다.
  `[id]`·`[slug]` 등 동적 라우트 폴더 안 106개가 오류 없이 빠져 Vercel 빌드가 실패했다(운영은 1011 유지).
- 보완(1012 보완 커밋): .NET 파일 API 로 복사하고, 커밋 전에 `git write-tree` 가 검증한 트리 해시와 같은지 확인해 다르면 멈춘다.
  같은 스크립트를 리눅스용 PowerShell 7 로 똑같은 상황을 만들어 돌려 통과를 확인했다. 이후 배포 스크립트는 이 방식만 쓴다.

## 4. 검증

- `npm run build` 전 체인 통과(단위 테스트 1,407 · 번들 예산 · JSON-LD · 캐시 정책).
- 폰(iPhone 13)·데스크톱 캡처: 뉴스 40행 모두 같은 높이(폰 91px · 데스크톱 97px), 모바일 조작 검사 5개 경로 통과.
