# 1189 · 임장노트 화면 단순하게

## 진행 전 재검토

| 요소 | 판단 |
|---|---|
| 사진 두 장 펼침(책처럼 넘기기) | 소유자 지시(1017)로 만든 것 — 그대로 둠 |
| 카드 머리의 아바타 원 · #태그 줄 · 사실 줄 · 아래 단추 줄 | 제목 · 사진이 같은 일을 함 — 걷음 |
| 왼쪽 메뉴의 "공개 노트 · 내 노트" | 머리의 전환 단추와 같은 것 — 걷음 |
| 폰 보기 단추 세 개(격자 · 피드 · 목록) | 두 개(피드 · 목록)로 |

## 바뀐 것

- 카드: 제목 + 점수 → 한 줄(작성자 · 시각 · 지역 · 단지 보기) → 발췌 두 줄 → 사진. 제목과 사진을 누르면 노트로 간다.
- 왼쪽 메뉴: 노트 쓰기 + 현장 퀵 기록 · 노트 비교 · 임장 가이드 + 지역.
- 폰: 보기 단추 피드 · 목록 둘.

## 확인

- 빌드 · 게이트 통과, 단위 테스트 2,686개 통과. 전후 이미지 2장(전 = 운영 · 후 = 로컬).
