## 3. 1073 — 공통 틀(모든 페이지에 한 번에)

페이지마다 고치면 다음 페이지에서 또 어긋난다(1012 · 1015 의 교훈). 토큰과 공통 부품에서 고친다.

1. **PC·태블릿 글자 단계**(`globals.css` 맨 뒤 [1073] 블록) — 위 기준안 값. `t-*` 를 쓰는 모든 자리가 같이 움직인다.
   토큰 대신 px 로 적은 글자(`text-[10/12/13/15px]` · `text-xs` 900여 곳)도 PC 에서 같은 단계로 읽힌다.
2. **간격 눈금 3.5 → 4px** — Tailwind 숫자 유틸 11,000여 곳(p-4 · gap-6 · mt-8 …)이 같은 비율로 넓어지고 8의 배수에 선다.
   px 로 적은 "정확해야 하는 크기"(아이콘·터치 칸)는 그대로.
3. **폰은 한 픽셀도 바뀌지 않는다** — 1026c 값 그대로(소유자: "모바일 버전이 다 좋다").
4. **화면 제목 한 단계** — 법적 문서 9쪽(text-2xl) · 다이제스트 · 없는 주소 2곳 · 전문가 신청 상태 · 내 임장 카드 · 프로필 ·
   위젯 · 데이터 출처 · 공개 API · 개발물건(md:21px 고정) → `t-title`.
5. **헤더** — "노트 쓰기" 한 줄 고정(1024px 에서 두 줄로 접히던 것).
6. **푸터** — 묶음 4개(서비스 · 데이터 · 회사·고객 · 약관·정책), PC 4열 · 폰 2열. 링크·라벨·목적지는 그대로.
   사업자 고지·수익 보장 미기재 문구는 그 아래 한 칸에 그대로 보인다(접지 않는다).
7. **넘침** — /creators 단계 설명(폰 539px 가로 넘침) · /auctions 입찰마감 날짜(칸 밖).
