## 로그인 "시도 한도 초과" 가 처음부터 뜨던 문제
- 원인: 공용 카운터(KV)가 운영에서 연결 실패(/api/health kv ok:false reason:network). 인증 경로는 카운터를 못 세면 "막음"으로 읽어, 가입 직후 첫 로그인부터 모든 비밀번호 로그인 · 비밀번호 찾기 · 매직 링크가 막혔다.
- 고침: 카운터를 못 세면 인스턴스 메모리 카운터로 내려 같은 상한(5분 10회)을 건다. 막지도 풀지도 않는다. auth.ts · lib/rate-limit.ts(failClosed 경로) · /api/me/password.
- 소유자 할 일: Vercel 의 KV_REST_API_* (또는 UPSTASH_REDIS_REST_*) 가 가리키는 KV 를 다시 연결하거나, 쓰지 않으면 변수를 지운다.
